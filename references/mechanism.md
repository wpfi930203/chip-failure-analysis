# 芯片失效机理诊断

## R · 原文锚点

> 失效模式是指器件失效的形式，只讨论器件是"怎样"失效的，并不讨论器件为什么失效。……从芯片内部的结构来看则有芯片与底座黏结不良或脱开、内引线断裂、内引线尾部过长、键合点变形或抬起、键合位置不当、内引线与引脚键合不良、芯片涂敷不良、芯片上有外来异物、芯片裂缝、铝穿透、氧化层划伤、断裂、针孔、过薄、龟裂、介质强度差、光刻对准不佳、钻蚀、毛刺现象等。
>
> ——第 12 章 12.2

---

## I · 骨架：先把「模式」与「机理」严格分开，再按「部位」检索

**两句话定死概念**：

- **失效模式 = 怎样失效**（外部表现，可观测）：开路、短路、参数漂移、壳体破碎、漏气、功能异常、间歇失效。
- **失效机理 = 为什么失效**（内部物理化学过程，只能推证）：电迁移、闩锁、栅氧击穿、腐蚀、分层、二次击穿……

混淆二者的后果是**把现象当结论**："这颗芯片短路了" 不是结论；"这颗芯片因闩锁效应导致电源对地短路" 才是。

**检索顺序**：先按**失效发生的部位**定位（芯片体内 / 装片 / 键合引线 / 封装 / 外部因素），再在该部位内查模式 → 机理。

## A1 · 案例：分立器件失效模式的定量分布

书内图 12-13 给出半导体分立器件主要失效模式及所占比例：

| 失效模式 | 占比 |
|---|---|
| 开路 | 35% |
| 参数漂移 | 28% |
| 壳体破碎 | 17% |
| 短路 | 13% |
| 漏气 | 4% |
| 其他 | 3% |

书里给的关键判断：**"随着半导体生产工艺的完善，由生产工艺引起的失效正在减少，越来越多的分立器件是由于使用不当造成失效的。"**

**这个判断对责任分析的直接意义**：当你看到一个分立器件失效，**先验概率上"使用不当"的比重在上升**。这不等于"不是器件的问题"，而是意味着**必须拿出工艺侧证据（结构缺陷、来料缺陷）才能把责任归于器件本身**——凭"器件坏了"就断定器件质量问题的做法，与这个分布是矛盾的。

## A2 · 案例：CMOS 闩锁引起芯片烧毁的完整链条

书里给出的机理链条（可直接作为报告模板）：

> **CMOS 电路中存在 PNPN 寄生晶闸管结构** → 在一定条件下被触发 → **电源到地之间流过较大电流**，并在 PNPN 寄生晶闸管结构中**同时形成正反馈过程** → 此时寄生晶闸管结构处于导通状态 → **只要电源电压不降至临界值以下，即使触发信号已消失，已经形成的导通电流也不会消失** → 引起器件的烧毁。

**可辨识特征**：闩锁的关键判据是**"自锁"**——触发源撤除后电流仍维持。这一条把闩锁与普通 EOS 过流区分开了：EOS 是"应力在，电流在；应力去，电流去"；闩锁是"应力去，电流还在"。

## A3 · 案例：塑封器件"爆米花效应"的完整失效链

某塑封 FPGA 在整机调试中无法写入程序。**多个端口对 GND 开路，但用力按压测试却可呈现与良品相同的特性曲线**（间歇性导通 → 机械接触问题的强提示）。切片观察发现：样品塑封料与 PCB 界面存在分层，PCB 表面绿油与基材的界面也存在分层或开裂，铜箔从基材上脱起。

**机理链**：塑封料内的水汽在高温下受热膨胀 → 使塑封料与芯片间发生分层效应 → 拉断键合丝 → 产生开路失效。

**为什么先做扫描声学（C-SAM）**：C-SAM 图直接给出"敷料与引线架界面分层"的位置，**在切片之前就锁定了分层界面**。切片只是去证实。

## E · 执行步骤

### 第 1 步：按部位检索失效模式（表 12-1）

| 部位 | 集成电路的主要失效模式 |
|---|---|
| **芯片体内** | 结特性退化、低击穿、芯片裂纹、漏电或短路、参数漂移；金属互连系统的开路、短路、漏电、烧毁 |
| **装片** | 芯片脱开龟裂、热点 |
| **键合引线** | 键合引线弯曲、焊盘凹陷、键合引线损伤、键合引线断裂和脱落、键合引线和焊盘腐蚀、键合引线框架腐蚀、键合引线框架的低粘附性及脱层、焊点疲劳损伤 |
| **封装** | 包封料破裂、包封材料疲劳裂缝、芯片表面漏电、芯片上的铝膜腐蚀、开路或短路、芯片裂纹、引脚脆裂开路、存储数据丢失 |
| **外部因素**（机械振动、冲击、过电应力、电源跳动） | 瞬间开路、短路、栅介质击穿或熔融烧毁 |

### 第 2 步：九类核心机理的辨识（书内 12.2.2 展开）

| # | 机理 | 物理过程 | 辨识特征 | 触发条件 |
|---|---|---|---|---|
| 1 | **栅介质击穿短路** | 生产过程中薄栅氧化层上的高电场是影响成品率与可靠性的主要因素。**电荷注入氧化层 → 产生结构变化（陷阱、界面态）→ 局部电流增大 → 足够多电荷注入时产生热损伤 → 氧化层出现低阻通道 → 不可恢复的漏电 → 击穿短路** | 栅-源/栅-漏短路或低阻；可用加电流或加高电场再现 | 薄栅氧 + 高电场；与尺寸等比缩小正相关 |
| 2 | **电参数退化** | 双极型：电流增益下降、PN 结反向漏电增加、击穿电压蠕变；**MOS：平带电压、阈值电压漂移、跨导下降、线性区漏极电流和饱和区漏极电流减小甚至源-漏击穿**；光电耦合器件：转移效率下降；光电器件：发光效率降低 | 参数随时间或应力单调退化 | 长期电/热应力；HCI、BTI |
| 3 | **金属化互连开路** | 两类原因：**① 加工工艺**——多层金属布线中，腐蚀法刻蚀铝和介质层上的通孔会造成金属边缘和氧化层台阶处第二层金属膜厚不均匀，从而引起断条；**② 使用**——金属条中电流密度过大，产生**金属原子的迁移**，导致金属化互连线断裂开路 | 开路；SEM 见铝条断条、楔形空洞、台阶处变薄 | 电流密度过大 → 电迁移（EM）；台阶覆盖差 |
| 4 | **芯片烧毁** | 过大的输入信号或电源电压加到芯片上时，产生器件的大面积烧毁，或芯片上产生严重的过应力击穿 | 大面积熔融、金属喷溅 | 过电应力（EOS） |
| 5 | **闩锁效应（Latch-up）** | 见 A2 | **自锁：触发源消失后导通电流不消失** | PNPN 寄生晶闸管被触发；电源电压高于维持临界值 |
| 6 | **电路漏电** | 本应绝缘或只应小电流的位置产生大得多的电流，**而且是数量级的增加**，电流大小与损伤部位有关。多层金属布线中，两层布线间有氧化层针孔及因第一层金属不平整或介质膜过厚引起的**介质膜裂纹**，破坏了介质的绝缘性能而产生漏电 | 漏电电流出现数量级跳变；OBIRCH 可定位到针孔/裂纹 | 氧化层针孔、介质膜裂纹 |
| 7 | **电路无功能** | 本应有信号输出的电路端口没有信号输出。**内因**：有输出信号端口的键合引线烧断使信号无法输出、键合引线的键合端腐蚀开路造成信号无法输出、内部电路短路使信号被旁路到地；**外因**：供电不足使电路不能输出信号 | 无输出；需区分"芯片内因"与"供电外因" | 键合烧断/腐蚀开路/内部短路；或供电异常 |
| 8 | **存储数据丢失** | 在外界因素作用下产生的电路误动作，使动态存储器存储的电荷丢失、静态 RAM 存储单元翻转、动态逻辑电路信息丢失，**与器件本身的物理缺陷无关** | 数据可复现性差、无明显形貌损伤 | 外界因素（瞬态干扰、辐照、电压跌落） |
| 9 | **保护电路烧毁** | 微电子器件在加工、生产、组装、储存及运输过程中可能与带静电的容器、测试设备及操作人员相接触，**所带静电经过器件引线放电到地，使器件受到损伤或失效，即静电放电损伤（ESD）**。它对各类器件都有损伤，而对 **MOS 器件特别敏感**。器件抗静电能力与器件类型、输入端保护结构、版图设计、制造工艺及使用情况有关 | 保护结构熔融/穿孔；输入端口漏电 | ESD；器件 ESD 分 **1、2、3 三个等级** |

### 第 2.5 步：功率器件与封装结构特化机理（v2.0.0，源自《典型案例》第8章/§1.5）

**功率器件六类特化机理**（与 IGBT/功率 MOS 封装失效域直接重合）：

| # | 机理 | 物理过程 | 辨识特征 |
|---|---|---|---|
| P1 | **二次击穿** | 正偏二次击穿与器件热性能有关，反偏与集电结载流子雪崩倍增有关；**两者都与内部电流集中过程密切关联**。大面积器件在大电流密度下发射极电流集边/集缩 → 局部温升"热斑" → **电热正反馈** → 空间电荷区消失、电压骤降电流剧增 → 局部熔化短路穿通 | 烧毁点位于键合区附近/发射区边缘；芯片碎裂分层（S-D 局部击穿 + 后续短路电流过热熔融） |
| P2 | **芯片焊接（烧结）失效** | 理想焊接界面应无内应力、无裂纹空洞、低欧姆接触、低接触热阻。沾污/镀层不良 → **浸润不良形成空洞** → 接触面积缩小、热阻增大 → 局部热点 → 热奔致命失效；且结温升高会加速电迁移等温度相关机理 | C-SAM 见焊接界面空洞/贯穿空层面；开封后焊料与底板未熔合、芯片边缘才有焊料 |
| P3 | **软焊料温循疲劳** | 各层材料 CTE 差异 → 功率循环/温度交变下芯片受拉伸压缩 → 硬焊料致芯片破裂/剥离，**软焊料层产生位移形变和剪切形变，多次反复后疲劳龟裂** → 热阻增大 → 烧毁 | 焊料层龟裂纹、断面疲劳特征；热阻/饱和压降随循环次数上升 |
| P4 | **Au-Al 键合系统退化** | Au 与 Al 化学势不同 → 生成 AuAl₂（**紫斑**）、Au₅Al₂、Au₄Al、AuAl、Au₃Al（**白斑**）等金属间化合物：电导率低、脆性、晶格常数与膨胀系数失配 → 键合强度下降、变脆开裂、接触电阻增大；**柯肯德尔效应**：高温（>300℃）下金向铝扩散快于反向 → 金层侧空隙聚积成空洞 → 界面强度急剧下降 | 键合界面紫/白色化合物区、柯氏空洞；时好时坏 → 最终开路 |
| P5 | **内涂/灌封胶应力裂纹** | 树脂内涂料耐温性差 → 温循筛选中产生内应力微裂纹 → 整机温循/振动应力下裂纹扩展 → **把金丝引线拉断** | 裂纹处引线拉断、胶体开裂；装机前筛选通过、整机环境试验中失效 |
| P6 | **Si-Cu（CTE 失配）结构应力裂纹** | 硅芯片直接焊到铜基座（CTE 差约 4 倍）且无钼片缓冲层 → 烧结冷却残存应力 + 机械应力 → **芯片侧面深裂缝和剥裂空洞** → 反向漏电漂升 + 大电流热效应 | 台面 PN 结处/芯片侧面连续裂纹；漏电流随通电时间漂升、175℃烘烤不恢复（区别于沾污） |

**补充机理（§1.5 增补，通用器件）**：
- **结穿刺（铝尖峰）**：Al-Si 接触 450~550℃ 热处理时硅在铝中固溶度远大于反向 → 界面硅原子净溶解进铝、铝填充硅中空位 → 铝"穿刺"透入硅衬底 → **PN 结短路**；
- **铝金属化再结构**：铝与 SiO₂/硅 CTE 不匹配 → 间歇工作温变下铝膜受张/压应力 → 表面粗糙、发黑、**小丘/晶须/皱纹**；
- **银迁移**：湿气 + 电压条件下银阳极氧化为 Ag⁺ → 电场驱动下向阴极迁移 → 途中形成氢氧化银乳白色污迹 → 阴极还原析出枝晶细丝 → **短路/耐压劣化**；
- **钝化层三缺陷**：裂纹（界面态增加 → 漏电漂移）、气泡（台面结非钝化保护区局部击穿）、针孔（扩散管道）——在环境应力下暴露为软击穿。

**b2 第8章统计判断（可直接引用到报告）**：所分析失效案例中「与芯片缺陷有关的失效案例很少……大部分与器件封装工艺密切相关，特别是芯片粘接工艺不良」——与 b1 "使用不当占比上升" 的判断互为印证：**功率器件失效优先查装片/键合/封装结构，其次才怀疑芯片本体**。

### 第 2.6 步：ESD 静电损伤机理（v2.0.0，源自邓永孝 1989 第10章专章）

> **判读中最容易被忽视的一条**（原文锚点，R 段同步收录）：静电损伤是与时间无关的偶然事件，**不能通过老练等筛选方法剔除**；老练中接地不良、传递不当反而会提高 ESD 失效百分比。ESD 使器件立即失效的几率约 **10%**，其余 **90% 是潜在性损伤**——电参数仍合格但抗过电应力能力已减弱，现场使用中表现为早期失效。

**两类失效模式（b4 §10.4）**：

| 模式 | 表现 | 细分 |
|---|---|---|
| **突发性完全失效** | 一个或多个电参数突然劣化、完全丧失功能（开路/短路/参数严重漂移） | **电压相关**：介质击穿、PN 结反向漏电增大、铝条损伤；**功率相关**：铝条熔断、多晶电阻熔断、硅片局部熔化 |
| **潜在性失效** | 一次 ESD 脉冲能量不足时不立即失效，但损伤**累积**——随脉冲次数增加，损伤阈值电压逐渐下降、参数逐渐劣化 | 由此推论：**对器件做 100% 抗静电筛选是不足取的**（筛选本身会引入累积损伤） |

**部位特征（判读用）**：
- 结型器件：损伤多在 **PN 结边缘的 Si-SiO₂ 界面或接触孔边缘**——ESD 局部高温→杂质微扩散→**杂质管道**→PN 结严重漏电、电流增益显著下降；
- 肖特基/浅结器件：损伤集中在**势垒区边缘 Si-SiO₂ 界面**（电场集中→热斑→失效），**失效模式完全类似于热致二次击穿**；
- CMOS：输入端铝互连线与 N⁺ 保护环间介质击穿短路、输入对地保护二极管 P 阱结击穿、多晶保护电阻接触孔损伤；严重时输入端金属化烧熔。铝栅器件 ESD 引发 Al-SiO₂ 界面反应，**Al 穿透 SiO₂ 致栅漏电/短路**；
- **CMOS 与 MOS 功率管**：ESD 可触发寄生可控硅**门锁**——供电回路无限流电阻时器件被过大电流烧毁。

**电流型损伤机理（b4 §10.5）**：
- **PN 结短路（合金钉）**：二次击穿焦耳热使局部温度超过 Al-Si 共晶温度 → 合金钉穿透 PN 结；SEM 下欧姆孔因失硅出现小坑。**衬底接地→纵向合金钉**（穿透扩散区底部）；**衬底浮空→横向合金钉**（从结边角伸向最近接地金属，电流集边效应加速）。版图对策：一个扩散区内设**多个小欧姆孔**（增周长）、**圆形接触孔**（避免电流非均匀流动）、增大接触孔与扩散区间距（防角落电流集中）；损伤阈值由放电通路中相邻窗口的**间距**决定——相距越远阈值越高。接触孔**过合金**形成的尖峰会诱发 ESD 失效；
- **铝/多晶硅大电流损伤**：铝互连线电流携带能力是其横截面积的函数——铝条**横跨陡峭氧化层台阶**处横截面减小，大电流 ESD 脉冲下易熔化开路；输入保护结构应**尽量靠近压焊点**以缩短铝互连线。

**三种 ESD 损伤模型（b4 §10.2）**：

| 模型 | 物理场景 | 要点 |
|---|---|---|
| **HBM 人体模型** | 带静电操作者经器件管脚对地放电 | 主要参数：放电时间 R·C 与总能量 E=½CV²；人体模型取 **R≈1.5kΩ、C≈100pF**；作为 ESDS 评估标准（MIL-STD-883C 方法 3015.2） |
| **CDM 充电器件模型** | 管壳与绝缘材料（塑料袋/传递容器）摩擦带电后经管脚对地放电 | 几个管脚同时接地即有几条放电通路，各自 R-L-C |
| **FIM 电场感应模型** | 器件处于静电场中感应出电位差；管脚相当于接收天线使电场畸变 | **MOS 器件放入 6000V/cm 静电场即可引发栅穿失效** |

**敏感度分级参考（b4 表 10-2，量级参考）**：MOSFET 100–300V、GaAs/FET 100–300V、CMOS 250–2000V、VMOS 30–1800V、肖特基 TTL 300–1500V、双极晶体管 380–7000V、ECL 500–1000V、SCR 680–1000V。集成度越高抗静电能力越低（器件尺寸小）。

**人体静电的环境依赖（b4 表 10-1，对防护规范设计有用）**：相对湿度 10–20% 时地毯走动可达 **85,000V**、坐在人造革椅 18,000V；相对湿度 65–90% 时分别降至 1,500V / 1,500V。**湿度是 ESD 防护的第一杠杆**；人体电容约 100pF、其中 60% 是脚底对地电容——单脚站立时人体电压远高于双脚。

> **与二次击穿的判读衔接**：ESD 烧毁与热致二次击穿的形貌可能高度相似（都在结区边缘、都有热斑熔融）。区分要靠**证据链**：失效前是否经历非受控操作环境（徒手接触、非防静电容器传递）、失效批次是否 100% 老练筛选、失效器件是否为高集成度/敏感器件类型。单一形貌不能定 ESD。

## B · 边界

1. **本章为 2015 年成书时的机理清单**。以下现代机理**不在覆盖内或仅被提及**，需另补标准：
   - 宽禁带器件的栅氧可靠性、动态 R_on 退化、体二极管退化；
   - 铜互连的电迁移与低 k 介质 TDDB 的现代模型（书内仅列为"挑战"）；
   - 2.5D/3D 封装、TSV 的应力与失效机理。
2. **"使用不当占比上升"是本世纪初的判断**，不可直接外推到你的产品线。要得到本单位的模式分布，必须自己统计。
3. **表 12-1 是"主要失效模式"清单而非穷举**，也不含概率。
4. **机理判定不能靠单点证据**。书内多次以案例说明"机理与原因必须分开论证"（见 `./chip-fa-router` 的 A1 案例）。同一机理可由设计、来料、工艺、筛选、装配、使用中的不同原因造成。
5. **本技能不给责任结论**。它给机理假设与所需证据，责任归属需在质量协议框架内另行认定。
