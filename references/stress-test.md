# 芯片应力试验设计

## R · 原文锚点

> 在失效分析中开展应力试验主要用来激发失效、复现失效模式或观察在应力条件下参数或参数分布的变化趋势，从而有助于分析失效机理，确定失效原因。
>
> ——第 2 章 2.4.6

---

## I · 骨架：在失效分析里，应力试验的作用不是"过标准"，而是"当判据"

常规可靠性试验里施加应力是为了**筛选或鉴定**；在失效分析里施加应力是为了**让假设可证伪**。

书里给了两个直接的范例：

- **想判断是不是离子沾污** → 做**高温偏置试验**，看端口漏电特性是否随时间和温度变化。沾污引起的漏电是**可动的**（离子迁移），因此随偏置与温度改变。
- **想判断是不是接触不良** → 做**振动试验**，看能否激发。接触类缺陷对机械应力敏感。

**因此设计应力试验的正确提问顺序是**：
1. 我的机理假设是什么？
2. 哪种应力对这个机理是"特征敏感"的？
3. 施加后我预期参数往哪个方向变？
4. 若不变，我能否排除该假设？

**不要**先问"标准里要求做哪些项目"——那是鉴定试验的逻辑，不是失效分析的逻辑。

**v2.0.0 增补（源自《典型案例》）**：应力试验在失效分析里还有**定量定位**作用——「通过应力试验可以评估产品的失效应力分布，确定产品发生失效的应力范围，达到统计中位失效数的中位失效应力水平……另外应力试验也有助于确定元器件**安全工作的极限应力水平**」。即：不只问"哪种应力能激发"，还可问"哪个应力水平上失效密度突变"——后者直接给出产品设计裕度的量化证据。

## A1 · 案例：单一环境应力的作用与典型相关失效（表 8-1 全表）

这是全书最可直接当"选应力"决策表用的一页：

| 环境应力因素 | 主要效应 | 典型相关失效 |
|---|---|---|
| **高温** | 热老化；氧化；结构改变；化学反应；软化、熔化及升华；黏度降低及蒸发；物理膨胀 | 绝缘失效；电气性能变化；结构失效；材料老化；丧失润滑性能；结构失效；机械应力增大，运动部件磨损增强 |
| **低温** | 黏度增大及凝固；脆化；物理收缩 | 丧失润滑性能；活性降低，电性能变化；丧失机械强度；裂纹，结构疲劳失效，运动部件磨损增强 |
| **高相对湿度** | 水汽吸收；化学反应；腐蚀；电解腐蚀 | 膨胀，腔体破裂；物理分解，丧失电气强度；丧失机械强度；功能退化，绝缘部件的电导率增大 |
| **低相对湿度** | 干燥；材料脆化；表面粗糙 | 丧失机械强度；结构瓦解；电气性能改变，粉末化 |
| **盐雾** | 化学反应；腐蚀；电解腐蚀 | 加速磨损；丧失机械强度；电气性能改变；功能退化，表面退化；结构被削弱，电导率增大 |
| **温度冲击** | 机械应力 | 结构瓦解或削弱，密封性被破坏 |
| **臭氧** | 化学反应；龟裂、裂纹；材料脆化；粗糙；降低空气的介电强度 | 快速氧化；电性能改变，丧失机械强度，粉末化；功能受到干扰；绝缘材料被击穿或出现电弧放电 |
| **分解的气体** | 化学反应；污染；减低介电强度 | 腐蚀；物理和电性能改变；绝缘材料被击穿或出现电弧放电 |
| **冲击/加速度** | 机械应力 | 结构瓦解 |
| **振动** | 机械应力 | 丧失机械强度，功能受到干扰，磨损加剧，结构瓦解 |
| **磁场** | 磁化 | 功能受到干扰，电特性改变，诱发加热效应 |
| **电压** | 电场强度增大 | 介质击穿，绝缘性能下降，加速电化学腐蚀 |
| **电流** | 电流密度增大 | 参数退化，过热烧毁 |
| **功率** | 功耗增加 | 参数退化，过热烧毁 |

**读表方法**：从"我怀疑的失效"反着往上找。例如怀疑"密封性被破坏" → 看"温度冲击"；怀疑"参数退化/过热烧毁" → 看"电流"或"功率"；怀疑"绝缘/介质击穿" → 看"电压"、"臭氧"或"分解的气体"。

## E · 执行步骤

### 1. 五类应力试验的适用判据

| 类别 | 施加方式 | 用于激发/判别的机理 |
|---|---|---|
| **温度应力** | 高温 | 热老化、氧化、化学反应、材料软化与蒸发 → 绝缘失效、电气性能变化、材料老化 |
| | 低温 | 脆化、物理收缩 → 机械强度丧失、裂纹、疲劳 |
| | 温度变化（温度循环 / 温度冲击） | 热失配机械应力 → **结构瓦解或削弱、密封性破坏**；温度冲击对密封性的针对性最强 |
| **温度-湿度应力** | 稳态湿热 | 水汽吸收、化学反应 → 膨胀腔体破裂、介电强度丧失 |
| | 交变湿热 | 反复水汽进出 → 电解腐蚀、绝缘部件电导率增大 |
| | 潮湿敏感性（MSD 评估） | 塑封料吸潮 → **分层 / 爆米花效应 / 键合拉断**（见 `./chip-fa-mechanism` A3） |
| **电学激励** | 电压加偏置 | 电场强度增大 → **介质击穿、绝缘性能下降、加速电化学腐蚀**；**高温偏置看端口漏电随时间/温度的变化 → 判别离子沾污** |
| | 电流 / 功率 | 电流密度增大、功耗增加 → **参数退化、过热烧毁**；电迁移试验 |
| **振动冲击** | 振动 | 机械应力 → 丧失机械强度、功能受干扰、磨损加剧、结构瓦解；**激发接触不良** |
| | 冲击/恒定加速度 | 结构瓦解 |
| **腐蚀性气体** | 盐雾 / 臭氧 / 分解的气体 | 化学反应、腐蚀、电解腐蚀 → 加速磨损、电导率增大、结构削弱；臭氧还会降低空气介电强度导致**电弧放电** |

### 2. 设计流程

```
1. 写下机理假设（H），例：H = 端口漏电由氧化层可动离子沾污引起
2. 选定特征敏感应力：温度 + 偏置（离子在电场与温度下迁移）
3. 设定观测量与方向：预期漏电随时间与温度变化（可逆或不可逆）
4. 设对照组：同一批好品做同样应力
5. 执行并记录"施加前 / 施加中 / 施加后"的完整参数曲线（不只看终值）
6. 判定：符合 → 支持 H；不符合 → 排除 H，回到第 1 步
```

### 3. 必守的操作纪律

- **必须先测基线**：施加应力前的参数与曲线是判据的参照，没有基线就没有结论。
- **必须有对照组**：好品在同样应力下的行为才是"正常"的定义。
- **必须看趋势而不是终点**：书内 LED 案例（见 `./chip-fa-electrical` A1）的价值就在"随时间单调上升"这个形状，单看一个终值无法论证机理。
- **应力类型要选"特征敏感"的那一个**：用振动试验去查栅氧击穿是浪费；用高温去查机械裂纹通常无效。
- **不要一次加多种应力**：多应力耦合会让归因失去唯一性。除非目的是复现而非归因。
- **设备与条件记录完整**：书里列出的常用设备包括高/低温试验箱、温度循环与温度冲击试验箱、潮热试验箱、振动试验台、HALT/HASS 试验箱 —— 报告里必须写明型号与设定值。

### 4. 常见设备的对应关系（书内 2.4.6）

| 应力 | 设备 |
|---|---|
| 高/低温 | 高、低温试验箱 |
| 温度循环 / 温度冲击 | 温度循环、温度冲击试验箱 |
| 温湿 | 潮热试验箱 |
| 振动 | 振动试验台 |
| 综合快速激发 | 高加速寿命 / 高加速应力筛选（HALT / HASS）试验箱 |

## B · 边界

1. **本技能不给具体试验参数**（温度值、湿度值、循环数、时长、判据阈值）。这些必须来自现行标准（IEC 60749 / JEDEC JESD22 / GJB 548 等）与客户规范。书内只给"类型—效应—失效"的映射。
2. **HALT/HASS 属快速激发手段**，用于暴露弱点，**不能用其通过来证明产品满足标准**；两者目的不同，不可混用。
3. **温湿试验与"潮湿敏感性等级（MSD）"不是一回事**：MSD 是器件对回流焊前烘烤/存放条件的分类（依据现行 IPC/JEDEC 标准），试验方法与筛选式湿热试验不同，详见 `./chip-fa-prevention`。
4. **应力试验可能使样品进一步损坏**。在失效分析流程中它应排在非破坏分析之后、破坏性制样之前，且需先确认样品是否唯一。
5. **加速因子外推需谨慎**：书内第 1 章指出"不同的失效机理加速应力各不相同"（电迁移用温度+电流，TDDB 用电压），**单一机理加速最有效**，而"一组应力条件有时也会激发多种失效机理"——多机理耦合时外推寿命会失真。
