> Open bonding is not easily detected by XRM. However, after EMC decapsulation, 2nd bonding lifted is exposed by optical microscope.
>
> ——开路线键合，X 射线不易检出；去塑封后光学显微镜才暴露二次键合脱落

## I · 骨架：五类分析活动的分工（**本技能此前完全缺失的维度**）

工业界把"拆开看"分成五种目的完全不同的活动，**接单第一件事是判断你要的是哪一种**——这决定了抽样方式、判据与结论形态：

| 缩写 | 全称 | **目的** | 抽样对象 | 结论形态 |
|---|---|---|---|---|
| **PFA** | Physical Feature Analysis 物理特征分析 | 鉴别**仿冒/翻新/改标**，验证标识、材料、结构、芯片版图与制造质量是否符合原厂工艺特征 | 采购批抽样 | 剔除/接收（针对样品批） |
| **DPA** | Destructive Physical Analysis 破坏性物理分析 | 验证**生产批的工艺与过程控制水平**（设计/结构/材料/制造质量是否满足规范或预定用途） | 生产批抽样 | 批质量信息；针对**不可筛选缺陷** |
| **CA** | Constructional Analysis 结构分析 | 从**结构设计**先期介入，评综合评价结构/工艺/材料是否存在预定使用环境（如宇航）下的可靠性隐患与潜在失效机理 | **典型样品** | **适用 / 限用 / 禁用** |
| **FA** | Failure Analysis 失效分析 | 对**已失效件**找失效模式、机理与原因 | 失效件 | 机理 + 原因 + 措施 |
| **EA** | Evaluation Analysis 适用性评价分析 | 评价器件对具体用途的适用性 | 按需 | 适用性结论 |

**为什么这张表重要**：把 FA 当成 DPA 做（拿失效件去判批质量），或把 DPA 当 CA 做（用批抽样去判设计隐患），结论都是无效的。**用户说"帮我分析一下这批货"时，先分清是 PFA / DPA / CA / FA 哪一种。**

**内在逻辑关系**（源的原文表述）：元器件固有可靠性由**结构设计**与**生产控制**两者决定——生产控制不严 → 内部工艺缺陷 → 靠 **DPA 剔除**；结构设计不合理 → 固有可靠性不高 → 靠 **CA 剔除**。

## A2 · 失效的四级分类（**定位"问题出在哪一类"的第一刀**）

| 类别 | 子类 | 说明 |
|---|---|---|
| **物理失效（结构）** Physical | 爆米花效应 Popcorn / 分层 Delamination / 开裂 Crack（封装或芯片） | 结构完整性破坏 |
| **电性失效（连接）** Electrical | 开路 Open / 短路 Short / 漏电 Leakage / 功能失效 Function | 电学特征异常 |
| **制程失效（生产）** In-Process | 前段（塑封前）/ 后段（塑封后）/ 测试（FT、老化） | 对应**工序定位表**的封装与测试区 |
| **可靠性失效（认证）** Reliability | 温度 / 湿度 / 压力 / 电压 | 对应鉴定与可靠性试验（模块 13/17/19） |

**用法**：拿到失效件，先在**这四类中归类**——物理失效走 SAM/制样路线，电性失效走电测+故障隔离路线，制程失效走工序回溯，可靠性失效走试验条件核对。这与报告模板第 8 节工序定位表是**正交的两个维度**（一个是"坏成什么样/在哪类"，一个是"出在哪个工序"），需交叉使用。

## A3 · 三大物理失效机理链（可直接写进报告机理段）

### ① 爆米花效应（Popcorn）—— 六步链

| 步 | 环节 |
|---|---|
| 1 | **吸湿**：L-1 级 85 ℃/85 %RH；L-3 级 30 ℃/60 %RH（分级浸泡条件） |
| 2 | **加热汽化**：回流焊 **235 ℃/10 s** |
| 3 | **蒸汽力导致分层** |
| 4 | **爆米花形成**：封装开裂 + 空洞塌陷 |
| 5 | **封装裂纹**（package crack） |
| 6 | **坍塌型空洞**（collapsed void） |

封装形态差异：**TQFP 常见底部爆米花**，**FBGA 常见顶部爆米花**。

### ② 分层（Delamination）—— 四个界面（判读时按界面定位来源工序）

| # | 界面 | 界面构成 | 指向的工序/原因 |
|---|---|---|---|
| 1 | Die surface | EMC / 芯片 | 塑封料与芯片表面粘接、芯片表面沾污 |
| 2 | Leadframe | EMC / 引线框架 | 框架处理、镀层与塑封料粘接 |
| 3 | Die Attach | 芯片 / 焊盘（装片区） | **装片（粘片）工艺**——功率器件高发 |
| 4 | Pad bottom | 焊盘 / EMC | 装片与塑封共同界面 |

### ③ 开裂（Crack）—— 两类 + 封装开裂四型后果递进表

两类：**EMC Crack**（环氧模塑料/胶体破裂）、**Die Crack**（芯片开裂）。

| # | 封装开裂类型 | 后果 | 严重度 |
|---|---|---|---|
| 1 | 封装背面开裂 | 防潮性能下降（**降幅最小**） | 最低 |
| 2 | 封装侧面开裂 | 防潮性能下降（小幅下降） | 低 |
| 3 | **跨越键合丝的开裂** | **金丝损伤、开路** + 防潮性能下降 | 高 |
| 4 | **封装正面开裂** | **金丝损伤、开路 + 金丝键合脱落** + 防潮性能下降 | 最高 |

> 这张表的工程价值：**开裂位置决定后果等级**，而非开裂大小。判读时要先定"裂在哪"，再定"要不要判废"。

## A4 · 键合缺陷中英判读术语表（**沟通与报告的标准词汇**）

### 引线键合（W/B，TSOP/BGA）

| 英文 | 中文 | **导致的电学后果** |
|---|---|---|
| Shift bonding | 键合偏移 | 短路 / 漏电 |
| Ball lifted | 金球脱落 | **开路** |
| Ball over-bonding | 过度键合 | 短路 |
| Ball neck broken | 金球颈部断裂 | — |
| Ball neck crack | 金球颈部开裂 | — |
| Heel broken | 根部（heel）断裂 | **开路** |

### 内引线键合（ILB，TCP/COF）

| 英文 | 中文 | 后果 |
|---|---|---|
| No bonding | 未键合 | 开路 |
| Poor bonding / Thin bump | 键合不良 / 凸点过薄 | 开路 |
| Thin lead | 引线过细 | 开路 |
| Alloy bubble | 合金气泡 | 短路 |
| IL shifted | 内引线偏移 | 短路 |
| Metal bridged | 金属桥连 | 短路 |
| Bump crush | 凸点压溃 | 短路 |

### 关键判读纪律（**与"金线脱落"类问题直接相关**）

> **X 射线不易检出开路型键合失效**；去塑封（decapsulation）后，**光学显微镜即可暴露二次键合（2nd bonding）脱落**，SEM 进一步确认形貌。

**推论**：若 X-ray 未见异常但电测确认开路，**不要据此排除键合问题**——必须去塑封后用 OM/SEM 看。这一条与总纲"先非破坏后破坏"不冲突：X-ray 是对密度差异敏感，对**界面分离**不敏感（界面分离看 C-SAM，键合脱落看去封后 OM/SEM）。

### 键合强度与失效的演进方向（可用于判读严重度）

`正常键合 → 漏电 → 短路`（功能失效 → 漏电 → 短路），键合力过大时 SiO₂ 层受损——**键合参数过冲本身就是缺陷源**。

## A5 · 短路 / 开路 / 漏电的具体成因清单（可直接作为排查表的候选行）

| 失效模式 | 具体成因（源文列举） |
|---|---|
| **开路** | 金丝颈部断裂；芯片损伤波及引线；引脚附着绝缘异物；焊盘污染（**俄歇光谱 AES 检测**）；二次键合断裂；载带产品内引线键合断裂 / 树脂致断 / 内引线剥离 |
| **短路** | 过度压合键合；键合偏移；引线框架间环氧树脂开裂；芯片电路烧毁；金线搭接基板指状线路；**锡须连接两引脚**；PCT（压力蒸煮）试验后焊料生长；PCB 卸载后焊料桥连；载带镀锡过厚；芯片划伤致电路短路；键合时针状锡生长；键合时金垫气泡 |
| **漏电** | 集成电路电路烧毁；芯片边角开裂；芯片开裂；芯片边角崩边 |
| **功能失效** | 组装相关——**机/人损伤**：边角崩边、侧面崩边、芯片表面划伤；组装相关——**环境（颗粒损伤）**：约 20 µm、约 10 µm 颗粒 |

### 锡须（Tin Whisker）生长四步机理（短路的重要隐蔽成因）

1. 基底元素（**Cu、Zn 等）沿晶界扩散进入 Sn 层**
2. **金属间化合物（IMC）优先在晶界形成**
3. Sn 层内产生**压应力**
4. 为释放应力，**锡须穿过 Sn 氧化物破裂处挤出**

> 判读含义：锡须是**应力驱动的扩散过程**，不是"脏污"；抑制方向是阻挡扩散层/合金化/应力释放，而非清洁。PCT 试验后观察到焊料生长属于同类应力-扩散现象。

## A6 · **EOS 与 ESD 判别表**（**填补 Desk Reference 章未取到的缺口**）

| 对比项 | **ESD**（静电放电） | **EOS**（电过应力） |
|---|---|---|
| **损伤外观趋势** | 损伤位置**极小**，肉眼无法识别芯片损伤 | 能量大时可见：芯片线路**熔断**、封装**变色/烧焦**；**能量小时与 ESD 难以区分** |
| **失效过程** | 电荷通过器件放电时损伤芯片 | 器件**工作中**（特性正被使用时）承受过压/过流而损坏 |
| **失效原因** | 带电体接触引脚放电；摩擦等在器件自身产生的电荷放电 | **闩锁效应**；开关机/测试仪器开关**浪涌**；**负载短路**；焊渣与金属异物造成的图形短路 |
| **芯片照片判读** | 需高倍率（损伤点极小） | 能量大时可见宏观烧毁形貌 |

### ESD 三大损伤模式

| 模式 | 机理要点 |
|---|---|
| **① 氧化层损伤（栅氧失效）** | 栅膜**仅 10 nm 级**，极易受损 |
| **② 结击穿** | **反向偏置**、**电流集中**、**浅结更易损坏** |
| **③ 线路膜熔断** | 热破坏；**ESD 熔化细铝线，EOS 可熔化粗铝线**；越细越易损 |

**IC 设计趋势带来的敏感性上升**：栅氧更薄、结更浅、铝线更细 → 对 ESD 更敏感 → **片上 ESD 保护电路成为必需**。

> **判别纪律（最重要的一条）**：**"小能量 EOS" 与 ESD 在形貌上无法区分**。因此——不能仅凭形貌判定是 ESD；必须结合**失效过程证据**（是否在带电操作/装配环节发生、有无浪涌或闩锁条件、失效比例与批次分布）。这与总纲 A1 案例"同一机理≠同一原因"是同一条纪律。

## A7 · 常规封装工序流（工序定位的参照基线）

**常规封装**：研磨 → 切割 → 粘片 → 键合 → 塑封 → 印字 → 切筋成型 → 电镀 → 测试 → 包装出货
**载带封装**：研磨 → 切割 → 载带 → 内引线键合 → 灌封固化 → 印字 → 测试 → 包装出货

## E · 执行步骤

1. **先定活动类型**：PFA / DPA / CA / FA / EA（I 段表）——决定抽样与结论形态。
2. **定失效大类**：物理 / 电性 / 制程 / 可靠性（A2）——决定分析路线。
3. **物理类** → A3 三机理链，按界面（分层）与位置（开裂四型）定位工序。
4. **电性类** → 按模式查 A5 候选行；键合类查 A4 术语表，并遵守"X-ray 查不出开路，去封后 OM/SEM 看"的纪律。
5. **疑似 EOS/ESD** → 用 A6 表，但**必须补失效过程证据**；小能量情形不得仅凭形貌定论。
6. **报告中统一用中英对照术语**（A4），避免与海外团队沟通歧义。
