## R · 原文锚点

> 有源微光探测技术利用光束和加偏置的元器件交互作用的现象来精确定位失效点。……如果激光波长小于半导体的带隙，就只有热产生；较短的波长但又超过带隙的激光将同时产生光子和热。然而，光子效应比热效应要强几个数量级，通常会占主导地位。……光束感生电阻变化（OBIRCH）、热感生电压变化（TIVA）、塞贝克效应（SEI）等技术则利用微光探测过程中产生的热来进行失效定位。
>
> ——第 6 章 6.1

## I · 骨架：定位手段的选择由「失效的电学特征」决定，不由设备偏好决定

一条几乎总是正确的决策链：

```
失效的电学特征是什么？
├─ 短路 / 呈现电阻性的金属互连 → 光子效应为主 → OBIRCH / TIVA
│    · 且样品为多层金属或倒装焊、只能从背面分析 → OBIRCH 尤其合适
├─ 开路（IC 内部，非金属互连电阻性） → 热效应为主 → SEI（塞贝克效应）
├─ 漏电 / 结异常 / 发光型缺陷 → 光子发射 → 微光探测（EMMI），须与良品对比
├─ 电压域异常 / 逻辑节点波形不对（VLSI 设计验证） → 电子束探针 EBT 电压衬度
├─ 封装内金属导体开路/短路、需完全不开封 → 磁显微（SQUID）
└─ 异常发热点 → 显微红外热像
```

**四条判据（书里给的关键约束）：**

1. **光子效应比热效应强几个数量级。** 所以选波长是选"要光子还是要热"——波长小于带隙只产热，大于带隙同时产光子和热。
2. **为避免光电流干扰，需采用能量小于半导体禁带宽度的光（常用 1340 nm）。** 即：当你不想引入光电效应、只要热时，用亚带隙长波长。
3. **微光探测必须与良品或同类正常区域对比。** 书里明说：正常器件也可能存在发光区域，不对比就会把正常发光当缺陷。
4. **倒装/多层结构只看顶部不行。** 光探测"既能从样品顶部又能从样品背面进行分析"，这对多层金属或倒装芯片封装非常重要——背面分析能力是选型的硬指标。

## A1 · 案例：用 EBT 电压衬度差找到"字线与电源线之间的微小短路孔"

对 4096 位 MOS 存储器做动态电压衬度分析：**先对好坏芯片的工作状态闪频电压衬度像做运算求差**，再按差值找故障点。

结果：存储器中有一条字线成为暗线（异常），而**相关译码电路没有异常** —— 这一"排除法"直接推出异常局限在字线与电源线之间。再由二次电子像证实：铝条字线与多晶硅电源线之间的绝缘层中有一个小孔，即短路位置。

这个案例的价值有两层：

- **方法论**：EBT 定位不是"看异常"，而是"好坏相减看差异"——单看失效片无从分辨。
- **推理**：**"应该异常却没异常"本身就是证据**（译码电路正常 → 排除译码路径），这一步比看到暗线更关键。

## A2 · 触发场景

- 「模块加电就短路，但不知道哪一颗芯片」
- 「封装不能开，能定位吗」（→ 磁显微 / 显微红外热点，非破坏）
- 「开封后做了 EMMI 没看到亮点，是不是没失效」
- 「OBIRCH 和 EMMI 该先做哪个」
- 「背面分析怎么做」

## E · 执行步骤

### 1. 先决定「要不要开封」

| 目标 | 可否不开封 | 手段 |
|---|---|---|
| 金属导体开路/短路定位 | 可以 | 磁显微（磁感应显微镜加外部电流，探测磁场变化） |
| 封装内热点定位 | 可以 | 显微红外热像（带锁定功能的增强型可分叠层芯片） |
| 芯片表面发光/结漏电 | 需开封或从背面 | 微光探测 |
| 电阻性互连故障 | 需开封（正面或背面） | OBIRCH / TIVA |
| 逻辑节点电压/波形 | 必须开封 | EBT |

### 2. 选手段（按失效电学特征）

| 手段 | 物理依据 | 适用失效 | 样品要求 |
|---|---|---|---|
| **微光探测（EMMI/光子发射）** | 载流子复合发光 | 结漏电、ESD/EOS 损伤、闩锁、栅氧击穿 | 开封，且**必须与良品对比**；可用光谱分析判定发光性质与类型 |
| **OBIRCH**（光束感生电阻变化） | 激光产热 → 电阻变化 → 电流变化 | 短路、**呈现电阻性的金属线** | 需开封；多层金属/倒装焊优先背面分析 |
| **TIVA**（热感生电压变化） | 同上，测电压响应 | 同 OBIRCH | 同上 |
| **SEI**（塞贝克效应） | 热 → 温差电动势 | **IC 中的开路路径** | 同上 |
| **LIVA**（光感生电压变化） | 光子 → 载流子 → 电压变化 | 同类 | 同上 |
| **EBT 电子束探针** | 二次电子能量 → 表面电位；可做波形取样 | VLSI 设计验证与失效定位 | 必须开封；束加速能 1 keV、束径 0.25 µm、电压分辨率 10 mV、等效带宽 4 GHz、时间分辨率 < 500 ps（本书给出的典型指标）；**必须有好坏芯片衬度差** |
| **磁显微（SQUID）** | 电流 → 磁场 | 开路、短路、漏电流 | 无需开封；低温 SQUID 磁灵敏度约 1 fT/Hz^1/2，高温约 10 fT/Hz^1/2，可做弱磁信号测量 |
| **显微红外热像** | 辐射峰值波长 ↔ 温度 | 异常热点、热性能 | 可不开封；可得平均温度分布与单点瞬态温度 |

### 3. 波长与样品处理

- 只想取"热"信号 → 用**亚带隙长波长（常用 1340 nm）**，避免光电流干扰。
- 想要光子发光信号 → 需波长超过带隙。
- 光探测定位的两步操作（书内明确）：**先在外部光源下对样品局部做实时数码照相 → 再在不透光的屏蔽箱中做微光探测成像 → 最后两像叠加**。目的是把发光点映射回真实物理位置。

### 4. 读图判据（避免误判）

1. **必须有好品或正常区域的对照**。否则无法区分"缺陷发光"与"正常发光"。
2. **差值为空不等于未失效** —— 可能是失效点在探测面之外（背面/下层金属），需换面或换手段。
3. **热点 ≠ 失效点**。大电流路径上的正常电阻也会发热；要结合电测（哪一对端口短路）判断。
4. **定位层次要匹配机理** —— 定位到"字线与电源线之间的绝缘层小孔"才能谈机理；停在"这个区域热"不够。

### 5. 与电测配合（不可省）

书里两次强调：电测用于**缩小物理分析区域**，而物理性能探测**需要电测试技术配合**（提供偏置与端口信息）。先用电测确定是哪对端口、什么电学特征，再选物理定位手段，顺序不能倒。

## B · 边界

1. 本章设备（2000 年代载体）型号已迭代；E 段给的是**选型逻辑与典型指标量级**，具体分辨率/带宽以现行设备手册为准。
2. 定位手段**不能替代机理判定**。定位给出"在哪里"，机理仍需靠形貌与成分分析（见 `./chip-fa-characterization`）。
3. 亚带隙波长只适用于**硅基**相对带隙的表述；对 SiC / GaN 等宽禁带器件，"亚带隙"对应的波长完全不同，切不可照搬 1340 nm。
4. 磁显微、显微红外热像依赖**加电条件**，对已开路（无法加电）的样品无效。
5. 本节内容以第 6 章为主，具体参数（如 SQUID 灵敏度）为**本书引用值**，反映的是成书时的技术水平。
