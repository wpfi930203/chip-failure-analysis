# 芯片气密性检漏（chip-fa-hermeticity）

## R · 原文锚点（≤150 字/段）

**R-1 泄漏速率定义**（《半导体器件可靠性与失效分析》§6.8）：
> 「定量的表示一个器件漏气的程度称为泄漏速率。……在 25℃下，半导体器件外部的气压为 1 个大气压，而器件内部已渗入的气压小于 1 毫米汞柱时……单位时间内从外部经漏孔流入器件内部的干燥空气的体积，为计算泄漏速率。」

**R-2 密封有效期**（同书 §6.8）：
> 「器件管壳内原有的保护惰性气体，因管壳漏气，器件内外的气体扩散、交换而逐渐丧失，通常以这种保护性气氛损耗百分之九十所需的时间来表征器件抗御外界环境影响的能力，即所谓器件密封有效期。」

**R-3 检漏标准的体积相关原则**（同书 §6.8）：
> 「脱离半导体器件具体情况，规定检漏标准是不科学的，由于器件内腔体积大小不一致，因此不能也不应该提出同一漏率要求。」

**R-4 粗细检分工**（同书 §6.8）：
> 「当被测器件的气密性小于 10⁻⁵ 大气压·厘米³/秒时，粗检的办法不能胜任，必须采用细检的办法。」

**R-5 特大漏孔必须先粗检**（同书 §6.8）：
> 「特别大的漏孔在放入氦检漏仪检测时，反向压入的氦已经逃逸尽，故无法检测。……如遇特大漏气，则无法辨别，因为大漏气的器件在 t₂ 时间内，器件内的氦气已全部逸出，使检测时无反应而误认为不漏。」

## I · 骨架（内化的判断逻辑）

1. **两套泄漏速率不可混用**：**计算泄漏速率 L**（真实漏率：25℃、内外压差≈1 atm、干燥空气，由测量值换算）与**测量泄漏速率**（质谱仪读数，与标准漏孔比对，氦介质）数值不同、单位相同（atm·cm³/s）。报告里不写明是哪一套，判废结论就不可复核。
2. **判废限值必须随内腔体积走**：内腔体积越小，同样漏率下保护气氛失守越快，限值必须更严。书中美军标准结构（5 atm 氦轰击条件）：V ≤ 0.1 cm³ → 测量值 > 5×10⁻⁸ 或计算值 > 5×10⁻⁷ 判废；V = 0.1–10 cm³ → 5×10⁻⁷ / 5×10⁻⁶。**数值本身以现行标准版本为准，但"限值是体积的函数"这一结构不变。**
3. **密封有效期是漏率的指数函数**：管壳内外交换 90% 气体所需时间 T 由氦漏率换算空气漏率后按经验公式求得（公式原文在 OCR 中丢失，仅存概念）。数量级直觉：漏率提高一个数量级 → 有效期缩短 10 倍；内腔体积越大，同漏率下有效期越长（书内表 6-4：V=0.1 cm³、L=10⁻⁷ 时约 3.6 天→不同体积从数十小时到数年不等，**用时必须按实际体积与现行公式重算**）。
4. **粗检与细检是互补而非替代**：漏孔 > 10⁻⁵ 粗检管；10⁻⁵–10⁻³ 用氟碳化合物加压法；> 10⁻³ 直接冒泡即可；< 10⁻⁵ 必须氦质谱细检。**顺序铁律：先粗检后细检**——特大漏孔在氦检中会因氦逃逸而"无反应"，被误判为气密合格（假阴性）。
5. **无损与破坏各有定位**：破坏性氦检（器件打孔直连质谱）精度 10⁻¹⁰–10⁻¹²，适合零件检漏、校对与方法仲裁，**不能用于成品筛选**；无损轰击法精度 10⁻⁷–10⁻⁸，表面吸附氦难吹净导致**重复性差**，做批次筛选时须规定吹净程序与等候时间。

## A1 · 案例

**案例（氟碳化合物加压法的工程参数结构，§6.8）**：真空室抽至 1 Torr 以下保持 1 h → 灌入低沸点 F-113，加压 3–5 atm 保持约 3 h（压力与时间随封装而异）→ 解除压力后置入 125±5℃ 高沸点全氟三丁胺（常压沸点 110℃）观察气泡。低沸点液体在腔内汽化产生内压，从漏孔冒泡，灵敏度达 10⁻⁵。**可迁移的结构**：灵敏度由"低压灌入—高温汽化—观察介质沸点差"三要素决定；汽化热越小、室温动态粘度越小，灵敏度越高。

**案例（氦质谱原理段）**：180° 磁偏转质谱计——氦离子经加速电场入磁场，按质荷比偏转半径分离（书内示例 R=4 cm、H=1450 Oe），只有氦离子通过离子闸到达收集极。理解此段即可判断仪器异常：本底氦升高（大气氦渗入真空系统）会让小漏孔读数淹没。

## E · 执行步骤

### 1. 检漏路径决策

```
待检器件（含密封腔体）
├─ 1. 先粗检（铁律，不允许跳过）
│   ├─ >10⁻³：125℃ 氟碳化合物直接冒泡（盖板倾斜/管壳开裂/焊料孔洞级大漏）
│   └─ 10⁻⁵~10⁻³：氟碳化合物加压法（低压灌入→高温观察）
├─ 2. 粗检通过（未见气泡）→ 细检
│   └─ 氦质谱轰击法：抽真空→高压氦轰击→吹净表面吸附氦→等候→质谱读数
│       → 换算计算泄漏速率 L → 对照"体积相关限值"判废
└─ 3. 仲裁/校对（抽样、非全检）
    └─ 破坏性氦检（打孔直连），精度 10⁻¹⁰~10⁻¹²
```

### 2. 操作纪律

- **氦检前必粗检**：防特大漏孔假阴性（R-5）。
- **表面吸附氦必须吹净**：干燥空气或氮气吹净管壳表面后再进质谱，否则读数虚高、重复性差。
- **记录五要素**：轰击压力/时间、等候时间 t₂、内腔体积 V、氦压 P_E、仪器读数——缺一项就无法换算 L。
- **换算透明**：报告同时给测量值与计算值，写明换算所用公式与标准漏孔校准状态。
- **判废限值成对引用**：引用标准时写全"轰击条件 + 体积档 + 测量/计算限值"四元组，只引一个数字是无效引用。

### 3. 与失效分析的接口

- 内部腐蚀 / 电参数漂移 / 内水汽超标的样品，气密性排查**排在开封之前**（检漏非破坏，开封破坏腔体）。
- 检漏合格 ≠ 永久气密：漏率只是当前状态，密封有效期 T 才是寿命语言——把 L 换算成 T 再进报告，才能与客户可靠性主张对接。
- 塑封/灌封器件无金属腔体，本技能的漏率体系**不适用**；其水汽侵入路径按 `./chip-fa-mechanism`（分层/爆米花）与潮敏标准处理。
- **JEDEC 口径（A109B，SemiAsk 一手蒸馏）**：JEDEC 自己不定义泄漏限值，A109B 是"指针"标准——商业密封产品按 **MIL-STD-750 TM1071**、微电路按 **MIL-STD-883 Method 1014** 执行；且 TC/TS/PCT 等环境应力试验的失效判据条款均自带"密封封装试验后补做检漏（A109）"。即：**环境应力后必复测气密**是 JEDEC 家族固定动作，限值判据的权威源头在军标——与边界 1 的指向一致。详见 `./standards-jesd22.md` 骨架三。

## B · 边界

1. **本技能不给现行判废数值**：书内美军标准限值为 1980 年版本结构，现行限值以 MIL-STD-883 Method 1014 / IEC 60068-2-17 / GJB 548 现行版为准。书内表 6-4 的有效期数值**不得直接引用**。
2. **经验公式（6-13/6-15）与氦检基本公式（6-17~6-20）在 OCR 中丢失**，本技能只保留概念与数量级关系；使用时必须从现行标准或教科书恢复公式，**不得凭本技能复现公式**。
3. 书内"冒泡法检 >10⁻³"的灵敏度数字为该年代工艺条件下的经验值，实际灵敏度随氟碳液体种类、器件热容量、观察条件变化。
4. OCR 证据注意：原文"氦"字多处被 OCR 误作"氨/氢/氮"，凡本技能引用数值处均已人工核对物理语境；如需回原文核对，用 `pdf-scan-ocr-pipeline` 重读对应页（b3 PDF p137–141）。
