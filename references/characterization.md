# 芯片显微与成分表征选型

## R · 原文锚点

> 显微形貌分析技术是对元器件进行外观和内部检查的技术，是进行失效定位和机理分析的最基本、最重要的手段。由于元器件在微观结构上达到微米甚至纳米级，因此，除了光学显微分析外，还包括扫描电子显微（SEM）分析、透射电子显微（TEM）分析等电子显微分析技术和手段。
>
> ——第 2 章 2.2.3
>
> 【v2.0.0 增补，源自《电子元器件失效分析与典型案例》第3章表3-1】X 射线透视「以低密度区为背景，观察材料的高密度区的密度异常点」；C-SAM「以高密度区为背景，观察材料内部空或低密度区」——**两者成像背景互补**。「X 射线透视技术对 MOS 器件有辐射损伤，所以无损不是绝对的。」

---

## I · 骨架：表征手段按「回答什么问题」分三层

```
① 形貌层：长什么样？
   OM（4~80 倍立体 / 50~2000 倍金相）→ SEM → TEM → AFM（三维表面形貌）

② 结构层：里面有什么缺陷？（可不开封）
   X 射线显微透视（2D/3D）→ 扫描声学显微（C-SAM）

③ 成分层：是什么材料？含量多少？
   SEM 配 EDS（Be 以后元素，微区定量）→ AES（表面极薄层）→ SIMS（微量、深度剖面）
   → XPS（化学态）→ FTIR（有机基团/污染物）→ 内部气氛分析（气密封装腔内气体）
```

**选型的两条硬约束**：

1. **空间尺度决定下限**。元器件结构达到微米甚至纳米级 → 光学显微镜只能做初筛；要看栅氧、结、界面，必须电子显微。
2. **要不要开封决定先后**。X-ray 与 SAM 是**无损**的，因此永远排在开封之前；一旦开封，无损信息再也拿不到。

## A1 · 案例：C-SAM 在切片之前锁定分层界面

某塑封 FPGA 无法写入程序。**多个端口对 GND 开路，但用力按压测试时可呈现与良品相同的特性曲线**。

C-SAM 图片显示：**塑封料与引线架界面分层**。据此再切片观察，证实样品塑封料与 PCB 界面存在分层，PCB 表面绿油与基材界面也存在分层或开裂，铜箔从基材上脱起。

**机理结论**：塑封料内的水汽在高温下受热膨胀，使塑封料与芯片间发生分层效应，**拉断键合丝**，产生开路失效。

**这个案例给出的方法论价值**：C-SAM 用无损方式探测裂纹、空洞和分层，**先在无损阶段把分层界面找出来，再让切片去证实**——如果反过来（先切片），你只能看到切开的这一个截面，看不到分层在平面上的分布范围。

**书里同时给了一条重要克制**：**"分层并不一定表示有可靠性问题。对于一个特定的芯片/封装系统，一定要明确分层对可靠性的影响。"** 换句话说，**报"有分层"不等于报"失效原因"**，必须论证分层是否导致了功能或寿命的劣化。

## E · 执行步骤

### 1. 决策表：看什么 → 用什么

| 要判读的对象 | 首选 | 备选 / 补充 | 样品要求 |
|---|---|---|---|
| 外部形貌、变色、裂纹、沾污初筛 | **立体显微镜 4~80 倍**（变换照明角度取最佳效果） | 金相显微镜 50~2000 倍 | 无损 |
| 失效部位初步定位 | **金相显微镜 50~2000 倍** | — | 无损 |
| 内部结构、内引线开路/短路、粘接缺陷、**焊点缺陷**、封装裂纹、桥连、立碑、器件漏装 | **X 射线显微透视（2D；分层扫描+计算机辅助可到 3D）** | — | **无损**，不破坏原形貌 |
| **分层**、空洞（尤其塑封器件分层） | **扫描声学显微（C-SAM）** | — | **无损**；对塑封器件分层特别有效 |
| 表面微观形貌（微米~纳米） | **SEM 二次电子像**（分辨率 1.5~5 nm） | AFM（三维表面形貌） | 需开封或在外部表面 |
| 表面成分定性（金属间化合物等） | **SEM 背散射电子像**（分辨率 50~1000 nm） | EDS | 需开封 |
| 微区元素定量（Be 以后元素） | **SEM + X 射线能谱仪（EDS）** | — | 需开封 |
| 极薄表面层成分（氧化、沾污、腐蚀产物） | **AES** | XPS | 需开封；超高真空 |
| 微量杂质、深度分布剖面 | **SIMS** | — | 需开封 |
| 元素的化学态 / 价态 | **XPS** | AES 部分可给化学位移信息 | 需开封 |
| 有机污染物 / 基团识别 | **FTIR** | — | 需取样，可与标准谱比对 |
| 气密封装腔内气体成分与水汽含量 | **内部气氛分析（IVA）** | — | 需在气密封装件上取样，破坏密封 |
| 原子级结构、界面、栅氧 | **TEM** | — | **必须用 FIB 做微区定点制样和提取** |
| 多余物成分 | EDS / FTIR / SIMS（视有机物/无机物而定） | — | 需取出多余物 |

### 2. SEM 的信号与用途对照（书内 2.4.8 给出，很实用）

高能入射电子轰击样品表面，被激发区域会同时产生：**二次电子、俄歇电子、特征 X 射线、连续谱 X 射线、背散射电子、透射电子**，以及在可见/紫外/红外光区的**电磁辐射**，还可产生**电子-空穴对、晶格振动（声子）**。

| 信号 | 典型用途 | 书内给出指标 |
|---|---|---|
| 二次电子 | **表面形貌特征观察** | 分辨率 1.5~5 nm |
| 背散射电子 | **表面成分定性分析**（如金属间化合物分析） | 分辨率 50~1000 nm |
| 特征 X 射线（配 EDS） | **微小区域元素定量分析** | 可测原子序数在 Be 以后的元素 |

### 3. 无损手段的读图判据

**X 射线透视**
- 原理：X 射线的**衰减程度取决于被检物与其内部缺陷介质的差异**，透过样品的强度差异在底片上表现为黑度差异。**属非破坏性检验，不破坏产品原有形状、不改变或不影响产品使用性能。**
- 判读：看内引线开路/短路、粘接缺陷、焊点缺陷、封装裂纹、桥连、立碑、漏装。
- 技术在从 2D 向 3D 发展（分层扫描 + 计算机辅助）；横向分辨率约 1 μm（由 X 射线波长决定）。

**X-ray 与 C-SAM 的互补选型（v2.0.0）**

| 手段 | 成像背景 | 擅长观察 | 注意 |
|---|---|---|---|
| X 射线透视 | **低密度为背景**，看高密度异常 | 高密度异常点：多余金属、焊点异常、互连短路 | **对 MOS 器件有辐射损伤**——检测前评估风险 |
| C-SAM | **高密度为背景**，看低密度/空腔 | 空洞、分层、芯片开裂等内部空气型缺陷 | 对塑封分层最有效 |

**C-SAM 四类粘接界面检查清单（v2.0.0）**：塑封层与芯片粘接界面、塑封层与引线架粘接界面、塑封层与基板粘接界面、芯片与基板粘接界面；另可查塑封料空洞与芯片开裂。功率模块的 DBC/焊料层空洞判定可按此清单扩展。

**OM vs SEM 选型（v2.0.0）**

| 对比项 | 光学显微镜 | SEM |
|---|---|---|
| 真空条件 | 不需要 | 需高真空 |
| 样品要求 | 开封即可 | 需去钝化层（荷电影响成像） |
| 理论空间分辨率 | ~3600 Å | ~50 Å |
| 最大放大倍数 | ~2000 | ~50 万 |
| 透明性 | **可观察多层金属化结构** | 只能观察最上一层 |

→ 实战推论：**多层金属化结构先 OM 后 SEM**——SEM 只看得到最上层，去掉一层前必须先把下层信息用 OM 拍全。

**密封性检查（气密封装）**：封装内水汽含量应保持在**几百 ppm 以下**（水分加速杂质离子迁移并腐蚀铝引线）。细漏用**氦原子示踪法**（氦质谱检漏），粗漏用**氟碳化合物检测**。用途：查封装微裂缝、焊料虚焊、焊接针孔与密封缺陷。

**扫描声学显微（C-SAM）**
- 原理：**回波脉冲的正负极性及其大小，由构成界面的两种材料的声学阻抗系数决定**；回波的极性与强度构成一幅反映界面状态缺陷的超声图像。
- 判读：分层、空洞、裂纹。
- **克制原则**：报分层必须同时论证"该分层是否影响可靠性"。

### 4. 内部气氛分析（IVA）的指标量级（书内以此型仪器为例）

- 质谱仪实际可用质量范围：**1~100 AMU**
- 水汽测试精度：2500 ppmV 时 ±20% 或更优；5000 ppmV 时 ±10% 或更优；7500 ppmV 时 ±10% 或更优
- 信号链：离子 → 四极杆质量分析器（时变电场使不同质荷比离子依次通过）→ 电子倍增检测器（二次电子倍增管，信号增益 10⁶~10⁸，配放大器可达 10⁶~10⁹）→ 质谱图

### 5. 作用定位（书内对"失效定位"的分层）

书里把"物理性能分析"单列为失效定位的核心手段（见 `./chip-fa-localization`），而把本节手段定位为**形貌 + 结构 + 成分**三条腿：

- **显微形貌分析** → 失效定位与机理分析的**最基本、最重要**手段
- **显微结构分析（X-ray / SAM）** → **不破坏样品**获取内部结构，探测空洞、断线、多余物、**界面分层**、材料裂纹，精度可到微米级
- **微区成分分析** → 结构改变常伴随成分变化；多余的杂质或沾污本身可能就是失效原因；**必须微区且微量**（ppm 甚至 ppb 级）

## B · 边界

1. **X-ray / SAM 是无损的，因此必须在开封之前做完。** 开封后再补是拿不到的（见 `./chip-fa-procedure`）。
2. **"检出了缺陷" ≠ "找到了失效原因"。** 分层、空洞、杂质都需论证其与失效的因果关系；书内对分层的克制表述就是范例。
3. **EDS 只给元素、不给化学态**；化学态需 XPS，有机基团需 FTIR。**EDS 对轻元素（Be 之前）无能为力**，此时需 AES 等表面手段。
4. **TEM 需要 FIB 制样，属于破坏性分析**，且制样难度大、周期长，只在需要原子级/界面级证据时才上。
5. **IVA 会破坏气密封装**，且只在气密封装器件上有意义；塑封器件无内部气氛可说。
6. **本章成书于 2015 年**：现代化手段（如高分辨 3D X-ray CT、超声相控阵、原位表征）未覆盖；设备型号与分辨率指标以现行手册为准。
