## R · 原文锚点

> 产品缺陷属于质量问题，而产品在保修期内频繁出现故障则属于可靠性问题。
> ——《评估半导体产品寿命的可靠性测试及标准》

> AEC-Q006 规定铜线键合器件的 TC、HAST/THB、PTC、HTSL 试验需做两倍应力（2X），并增加 CSAM、键合剪切/拉力和剖面检查等物理分析。
> ——《一文了解芯片可靠性测试》附录 AEC-Q006 解读

## I · 骨架：可靠性测试 = "浴盆曲线三段 × 应力类型 × 认证标准"三张表

### 表 A · 常用考核项目 — 条件与判据（量化）

| 项目 | 缩写 | 典型条件 | 判据/失效机制 |
|---|---|---|---|
| 高温工作寿命 | HTOL | 125℃，额定偏置，500~1000h | 电参数（漏电、Vth）漂移 ≤10~20%；FIT 达标（如 ≤10 FIT） |
| 低温工作寿命 | LTOL | 低温+偏压 | 评估热载流子（HCI）失效概率 |
| 高温存储 | HTSL/HTST | 150℃ 氮气炉，500~1000h | 扩散/氧化/**IMC 生长**/材料降解（评估键合 IMC 的主手段） |
| 温度循环 | TC/TCT | -65~+150℃，500~1000 次，气态介质，温变速率 1~5℃/min | CTE 失配疲劳：分层、封装裂、焊点断；ECU 需 1000 次验证 10 年寿命 |
| 热冲击 | TS/TST | 液浴双槽，转换 ≤1min，温变速率 ≥30℃/min，10~100 次 | 瞬时应力：脆断、键合点脱离、气密封装泄漏（与 TC 的分界见下） |
| 温湿偏压 | THB | 85℃/85%RH + 偏压 | 铝腐蚀为主 |
| 高加速温湿 | HAST | 110~130℃/85%RH，偏压 1.1~1.3 倍额定，96~168h，约 2.3 atm | 漏电增加 ≤1 个数量级；腐蚀/分层 |
| 高压炉 | PCT | 130℃/85%RH/2 atm（100%RH 饱和） | 厚封装耐湿；对薄封装应力过大，**引线框架产品用 PCT、基板产品用 UHAST** |
| 无偏压高加速 | UHAST | 85%RH 非饱和，无偏压 | 电偶腐蚀/直接化学腐蚀 |
| 功率温循 | PTC | 温循 + 周期通断电 | 通断电+温度复合 |
| 高温反偏 | HTRB | 125℃ + 反向偏压，数百小时 | 反向漏电稳定性（用户 HV-H3TRB 即此族） |
| 湿热反偏 | H3TRB/WHTOL | 85℃/85%RH + 反偏，500h | 湿气致金属迁移/绝缘下降 |
| 电迁移 | EM | 电流密度 ≥1×10⁶ A/cm²，150~250℃ | 电阻变化率 ≤10%，无断/短路 |
| NBTI | — | 125~150℃，负偏 1000h | ΔVth ≤50mV |
| 机械冲击 | MS | 1500G，3~5 次/方向（车规更高） | 无破损、无焊球断裂 |
| 振动 | — | 10~2000Hz，20G | 电参数稳定 |
| 焊球剪切 | BS | 剪切速度 100~500μm/s | 满足 JESD22-B117 |
| 气密检漏 | — | 氦质谱/压力染色 | 漏率 ≤1×10⁻⁸ atm·cc/s（军标更严） |
| ESD/LU | HBM/LU | HBM ±2~8kV 分级；LU 注入 100~500mA | 无不可恢复闩锁 |

### 表 B · TC 与热冲击（TS）选型分界（易混点）

| 维度 | 温度循环 TC | 热冲击 TS |
|---|---|---|
| 温变速率 | 1~5℃/min（渐变） | ≥30℃/min（骤变，双槽转换 ≤1min） |
| 应力本质 | **长期疲劳累积** | **瞬时极限应力** |
| 典型失效 | 材料疲劳裂纹、焊点蠕变、分层 | 脆性断裂、键合点/凸点脱离、气密封装泄漏 |
| 标准 | JESD22-A104、IEC 60068-2-14 | JESD22-A106、MIL-STD-883 |
| 适用 | 寿命预测、材料匹配（消费/车规/工业） | 极端环境验证、工艺缺陷筛查（航天/功率模块快速启停/回流抗裂） |

**判读规则**：失效怀疑"疲劳累积"选 TC；怀疑"瞬时脆断/键合脱离"选 TS。两者失效模式不互斥但敏感性不同，TC 复现不出来的缺陷可能在 TS 下暴露，反之亦然。

### 表 C · 认证标准地图

| 标准 | 范围 | 关键点 |
|---|---|---|
| JEDEC JESD22 系列 | 通用可靠性测试方法 | JC-14 固态产品质量与可靠性委员会制定；A104（TC）、A106（TS）、B117（剪切）、B120（Wire Pull） |
| AEC-Q100/Q101 | 车规 IC/分立器件 | 温度等级 Grade 0: -40~150℃ |
| **AEC-Q006** | **车规铜线键合器件**（2016 发布） | TC/HAST/THB/PTC/HTSL 全部 **2X 应力**；强制增加 CSAM + 球剪/球拉/切片物理分析 |
| AEC-Q102 | 车规光电器件 | HTOL/HTSL/HTRB/PTC/WHTOL/TC 矩阵 |
| MIL-STD-883 | 军用 | 条件更严苛 |
| IEC 60068-2-14 | 温变速率 | — |

### 预处理（Precon）——环境试验的先决条件

顺序：**热循环 → 烘烤（125℃/24h）→ 吸湿（蒸汽老化）→ 回流焊**。模拟运输-开箱-装机的吸湿与热应力，是 THB/HAST/TC 等环境试验的前置步骤；失效机制即**爆米花效应/分层**。判读意义：塑封器件环境试验前必须先 Precon，否则失效归类无法与客户端工艺对齐。

## E · 执行步骤（何时用本模块）

1. 用户问"某试验怎么做/条件是什么/判什么指标" → 查表 A + 表 C（对应标准）
2. 用户在 TC 与热冲击之间犹豫 → 表 B 分界规则
3. 涉及铜线键合器件车规认证 → **AEC-Q006 的 2X 应力 + 物理分析强制项**（即使不用铜线，"可靠性试验后加做 CSAM+拉力+切片"的组合也是键合可靠性评估的标准范式）
4. 设计试验矩阵 → 先 Precon、后环境应力、试验前后物理分析对照

## B · 边界

1. 本模块为**公众号二手源（L2）**，数值是行业通行量级；**认证用途必须回标准原文现行版核对**（AEC/JEDEC 版本更新频繁，如 AEC-Q100 Rev 已到 J 之后）。
2. 表 A 条件随封装形式、应用等级（消费/工业/车规/军标）变化，表中为"典型"而非"规定"。
