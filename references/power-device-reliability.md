## I · 骨架：功率器件可靠性试验的三个层次

| 层次 | 目的 | 典型项目 | 失效性质 |
|---|---|---|---|
| **① 磨损试验（wear-out testing）** | 复现现场长期退化，拟合寿命模型 | **功率循环 PC**（ΔTj/Tjm 双变量）、温度循环 TC、湿热 | 磨损失效（设计裕度问题） |
| **② 异常条件试验（abnormal condition）** | 验证极限工况下的鲁棒性 | 短路、过压、过流、过温 | 突发/灾难性失效 |
| **③ 在线监测（condition monitoring）** | 运行中获取退化量，预测剩余寿命 RUL | V_CE(sat) / 热阻 / 键合线状态在线测量 | 服务于寿命预测而非判定 |

**与通用可靠性试验的关键差别**：通用器件（JESD22 系列）以"通过/不通过"的鉴定思维为主；功率模块以**寿命量化**思维为主——要的是 N_f（失效循环数）与 ΔTj 的关系曲线，而不是 1000h 后是否还通。

## A1 · ALT 设计原则（功率器件版）

1. **应力水平不得改变失效机理**：加速应力（ΔTj、Tjm）加大到出现新机理（如超过材料软化点、进入二次击穿）时，外推无效——曲线拐点即机理切换点，必须识别出来。
2. **每应力条件样本 6–12 只**（教程建议值）：功率模块成本高、台架昂贵，样本量受预算约束，因此**必须用威布尔/对数正态拟合给出置信区间**，不能只报中位数（见 `reliability-stats.md`）。
3. **ΔTj 与 Tjm 必须双变量控制**：只报 ΔTj 不报 Tjm 的寿命数据不可比——LESIT 结果明确显示同一 ΔTj 下 Tjm 从 60℃ 升到 100℃，寿命可差一个数量级量级。
4. **失效判据前置定义**：V_CE(sat) 上升 5%？热阻上升 20%？还是键合线 lift-off 检出？判据不同，N_f 不同，报告必须写明（对应 `report-template.md` 第 4 节）。

## 寿命模型族（系数需按器件/封装标定，本模块不提供通用系数）

| 模型 | 形式 | 引入的变量 |
|---|---|---|
| **Coffin-Manson** | N_f = A·ΔT_j^(−n) | 仅 ΔTj（最简，工程粗估） |
| **改进 Coffin-Manson** | N = A·ΔT_j^(−n)·exp(E_a / k_B·T_jm) | 加中位结温 Tjm（温度加速项） |
| **Norris-Landzberg** | 含 ΔTj 与温度/频率项的指数修正 | 加循环频率效应 |
| **Bayerer (2008)** | N_f = f(ΔT_j, T_jm, t_on, I, U, **ar**, …) | 引入**键合线高跨比 ar**（弧高/焊点间距）、导通时间、电流电压；含二极管占比修正 |
| **Semikron (2013)** | N_f = A·ΔT_j^(−n)·(ar)^β·… | 同样纳入 ar 与工艺参数 |

> **读表纪律**：ar（bond wire aspect ratio = 弧高/焊点间距）是功率模块寿命的**设计变量**——同一电气规格下，键合线弧高与跨距的几何设计直接改变 N_f。这也是"键合线 lift-off 为何是功率模块首要磨损机理"的量化依据。

## 台架与工况（可直接对标设计自己的试验）

| 场景 | 参数（教程实例） |
|---|---|
| **MW 级 IGBT 模块 DC 功率循环** | 10 只模块并行；DC 2000 A；回路电感 L = 5 μH；水冷；LabVIEW/NI 控制；示例器件 1700 V / 1000 A、P_tot 6.25 kW |
| **变换器级老化（更接近工况）** | DC-link 1000 V；负载 650 A_rms；输出频率 6 Hz；开关频率 2.5 kHz；冷却液 80℃（水+乙二醇） |
| **在线监测接线** | **通态**测 V_CE 推算结温；**断态**注入约 500 mA 小电流测温；同一采样窗口内同时监测键合线状态 |

## 失效演进三阶段（功率模块老化曲线）

```
退化量 ↑
   │        ┌────────────── 灾难性失效（Catastrophic）
   │       ╱
   │   ╱──╱  ← 键合线 lift-off 期（Bond wire lift-off period）
   │ ╱
   │╱  正常磨损期（Normal wear）
   └────────────────────────────→ 循环数
```

**工程含义**：键合线 lift-off 是**可监测的中间阶段**，不是终点。在线监测的价值窗口就在这个"平台期"——在灾难性失效前检出（对应本模块 ③ 层次与 `closed-loop.md` 的归零验证）。

## 现场失效分布示例（用于建立"失效模式占比"直觉）

教程给出的光伏逆变器现场数据：**450 套系统 / 27 个月 / 3600 张服务工单**，失效工单集中于**逆变器子系统**（而非组件/结构/外部）。这类数据的用途是**校准"先查哪个环节"**——与 `report-template.md` 工序定位表的 F 区（试验/应用环节）互为印证。

## E · 执行步骤

1. 明确目标：鉴定（pass/fail）还是寿命量化（N_f 曲线）→ 决定走 JESD22 族还是本模块 PC 族。
2. 定义失效判据（V_CE / R_th / lift-off 检出）并写进方案。
3. 设计应力矩阵：至少 2–3 个 ΔTj 水平 × 明确 Tjm；每条件 6–12 只。
4. 跑试验 + 在线监测（通态 V_CE + 断态小电流测温同步）。
5. 威布尔拟合 + 置信区间；选模型（C-M 族起步，有 ar/t_on 数据则用 Bayerer/Semikron）。
6. 外推现场寿命时**必须声明**：模型系数为本批次标定值，跨封装/跨厂商不可直接套用。

## B · 边界

1. 源为 **2019 年会议教程（IPFA 2019）**，属一手二级源（L1.5）：方法论可靠，但**模型系数、台架参数为作者实例值，不是标准限值**。
2. 样本量 6–12 为教程的统计建议，**不是** AQG 324 / IEC 60749-34 的判据要求；认证用途须回标准原文。
3. 本模块表格中的公式形式已做 OCR 噪声过滤（原 PDF 公式排版在抽取中失真），**系数与指数一律以原文/厂商数据手册为准，本模块不复原具体数值**。
4. 功率循环与温度循环的区别：`standards-jesd22.md` 的 A122A（功率循环）是非等温 DC 循环方法，本模块给的是**寿命建模与台架实施**视角，两者互补，判据仍以标准为准。
5. SiC/GaN 器件的退化机理（栅氧、动态 R_on）与本模块 Si 基功率循环模型**不完全通用**，外推需另证。
