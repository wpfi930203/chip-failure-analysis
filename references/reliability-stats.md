# 可靠性统计与寿命分析（chip-fa-reliability-stats）

## R · 原文锚点（≤150 字/段）

**R-1 形状参数 m 的物理判读**（《半导体器件可靠性与失效分析》§3.2，p55）：
> 「当m=1时，可以认为它接近于指数分布，当m=2时，可以认为它是接近于瑞利分布的；当m>3.5时，可以把它当作正态分布处理；当m<1时，可以认为它接近于伽玛分布。」

**R-2 浴盆曲线三阶段**（同书 §1.4，p23–24）：
> 「第一阶段称为早期失效期或老炼期这一阶段失效率较高，但随时间增长而下降。其失效的原因是由于设计、制造中的缺陷造成的。……第二阶段称为偶然失效期……失效率较低并且接近于常数，是产品最佳的工作阶段。第三阶段称为耗损失效阶段……失效率随时间明显上升。」

**R-3 加速寿命试验定义**（同书 §3.3，p68）：
> 「所谓加速寿命试验就是用加大应力的方法促使样品在短时期内失效，从而预测电子产品在正常贮存条件或工作条件下的可靠性。」

**R-4 加速变量的选择原则**（同书 §3.3，p69–70）：
> 「在选择加速变量时，就要选择那种对主要失效机理起主导作用的应力条件。半导体器件常选择温度作为加速变量。」

**R-5 恒定应力法的定位**（同书 §3.3，p69）：
> 「三者比较起来，恒定应力加速寿命试验造成失效的因素较单一，准确度较高，试验较容易取得成功；但试验周期比较长。」

**R-6 加速系数定义**（同书 §3.3，p72）：
> 「在基准应力条件下进行的试验与某种应力条件下的加速试验达到相同的累积失效概率所需时间的比值称为加速系数或加速因子。」

**R-7 真实加速的警告**（同书 §3.3，p69）：
> 「加速试验的主要缺点是产品在高应力下的退化方式可能与正常应力水平下的不同。理想的情况应该是高应力水平作用下的器件退化方式与正常应力水平下的应仍然相同，唯一不同的只是时间加速了。」

## I · 骨架（内化的判断逻辑）

1. **三个函数各答一个不同的问题，不可混用**：F(t)=P(T<t) 回答"到 t 为止坏了多少"；f(t)=dF/dt 回答"失效在什么时刻最密集"（做筛选窗口设计）；λ(t)=f(t)/R(t)=f(t)/[1−F(t)] 回答"活到 t 的产品接下来单位时间坏多少比例"。三者关系与 R(t)=exp[−∫λ(t)dt] 是全部推导的起点。
2. **指数分布是"分界线"不是"默认"**：λ≈常数 ⇔ R(t)=e^{−λt} ⇔ MTTF=1/λ ⇔ 中位寿命 t₀.₅=0.693/λ ⇔ 可靠寿命 t_R=−lnR/λ（R=99.99% 时 t 仅 0.0001·MTTF）。**只有 m=1（威布尔形状参数为 1）时才允许整套指数公式**；m<1 说明早期失效未筛净，m>1 说明进入耗损。
3. **威布尔概率纸是半导体器件失效数据的"万能初判工具"**：r=0 时 F(t) 在纸上呈直线 y=mx−b。**操作链**：失效时间升序排（截尾只排已失效的；周期测试时失效时间取测试周期中点）→ F(tᵢ)=(i−0.5)/(n+1)（n≤20 查中位秩表）→ 描点 → 目测配回归线（**F(t)=30–70% 区间偏差优先压小**，两端 10% 以下可放松）→ 过 m 估计点 (1,0) 作平行线读 Y 轴截距得 m̂ → 回归线与 Y 轴交点得 b → t₀=e^b（或与 X 轴交点 a，η=e^a）。
4. **描点不成直线 ≠ 不服从威布尔**：先做直线化尝试——r>0（保证寿命，t<r 不可能失效）：曲线顺势延到 t 轴的交点即 r̂，全点左移 |r| 重描；r<0（试验前已有失效）：F(t)=A+(1−A)·F₀(t) 修正后右移尝试。反复试仍不成直线，才判"非纯威布尔"，换对数正态概率纸。
5. **数据超量程用缩放变换不改形状**：t=t′·10^α 后 m 不变、t₀=t₀′·10^α、η=η′·10^α；F(t)<0.1% 的高可靠外推可将概率纸 F 轴向下逐级扩展（每级 ÷10，位移 ln10）。
6. **加速试验三方案中恒定应力是默认选择**：恒定（因素单一、准确、周期长）/ 步进 / 序进。方案设计三要素：**加速变量**取对主导失效机理起主导作用的应力（半导体首选温度/结温）；**水平数 l≥4 且不得少于 3**，最低水平 S₁ 尽量靠近正常应力、最高水平 S_l 必须保证失效机理不变；**每组样品 nᵢ≥5**，同批随机抽取再随机分组。
7. **两套加速方程覆盖两类应力**：温度应力用 Arrhenius，积分得加速方程 **lgt(F₀)=a+b/T**（单对数纸直线，b=T₁T₂·lg[t₁/t₂]/(T₂−T₁)），激活能 **E=2.303bK**（K=0.8617×10⁻⁴ eV/K）；电压应力用逆幂律 **lgt=−C·lgV−lgK**（双对数纸直线，C=lg[t₁/t₂]/lg[V₂/V₁]）。电应力影响不大时可把 f(V)、f(I) 并入常数 a 继续用温度模型。
8. **激活能是机理指纹**：同一累积失效概率下，E 越大越容易被加速（加速系数 τ=exp[(E/K)(1/T₀−1/T₁)]）。可由测得 E 反查失效模式（书内表 3.2：表面劣化 0.4–0.5；Au-Al 金属间化合物 1.02–1.04；Al 电迁移小晶粒 0.48/大晶粒 0.84；SiO₂ 中 Na⁺ 扩散 1.39 eV 等）。
9. **抽样检验的前提常被忘记**：生产质量均匀稳定是抽样有效的前提；子样特性不能简单代替母体特性（1% 不合格率抽 100 只不一定抽到 1 只坏）。计数/计量两分，一次/二次/序贯三种方式；调整型（正常—加严—放宽联动）用于连续生产，标准型用于无历史资料的孤立批（需较大样本同时控 α/β 两类错误）。

## A1 · 案例

**案例 1（HV-H3TRB 数据拟合路径）**：74 pcs 168H + 23 pcs 1000H + 6 pcs 1500H 的分级截尾数据——按失效时间升序（多数未失效即为截尾）→ 中位秩表算 F(tᵢ) → 威布尔概率纸描点。若 m<1：早期失效未筛净，回到工艺查钝化/沾污；m≈1：转入指数模型用 MTTF=1/λ 汇报；m>1：存在耗损机理，须确认失效机理后再外推。**关键纪律**：0 失效的数据不能估 m，只能给置信下限——不要硬描直线。

**案例 2（加速系数反查机理）**：两组温度各得同 F₀ 的中位寿命 → 求 b → E=2.303bK。若 E≈1.0 eV 且形貌见紫斑，与表 3.2 Au-Al 界面（1.02–1.04 eV）自洽；若 E≈0.45 eV，指向表面劣化。E 值与形貌结论矛盾时，优先怀疑"高应力下换了机理"（R-7），外推作废。

## E · 执行步骤

### 1. 数据分析路径决策

```
寿命/失效数据到手
├─ 0. 数据体检：截尾方式、样本量、测试周期、失效判据是否成文
├─ 1. 威布尔概率纸描点（n≤20 用中位秩表）
│   ├─ 直线 → 读 m̂ → 按 R-1 判读机理阶段 → 估 t₀/η/MTTF/t_R
│   ├─ 曲线 → 直线化尝试（r>0 左移 / r<0 修正）→ 成直线再估参
│   └─ 仍曲线 → 对数正态概率纸重试 → 仍不成的判"非纯分布"，分组处理
├─ 2. m̂ 判读（R-1）
│   ├─ m<1：早期失效 → 反馈筛选/工艺，不做寿命外推
│   ├─ m≈1：指数模型 → MTTF=1/λ、t_R=−lnR/λ
│   └─ m>1：耗损机理 → 必须先做失效分析确认机理再外推
└─ 3. 报告：给点估计同时给依据（n、截尾数、F(t) 范围、图估/数值法）
```

### 2. 加速寿命试验设计流程

1. **定机理**：先用失效分析明确要加速的主导失效机理（R-4），预测其激活能。
2. **定变量与水平**：半导体默认温度/结温；l≥4（最少 3），S₁ 贴近正常应力，S_l 做小样验证机理未变；各水平间隔均匀。
3. **定样本**：同批合格品随机抽，随机分组，nᵢ≥5；低应力组样本量最大。
4. **测试周期**：每个周期内力争出现 1–2 个失效；累积失效约 60% 截尾即可统计推断。
5. **数据处理**：各应力水平分别做威布尔图估 → 各取同 F₀ 的 tᵢ → 单对数纸画 lgt–1/T 加速直线 → 求 b、E=2.303bK、τ → 外推正常应力寿命。
6. **真实性校验**：对最高应力组开封做失效分析，确认机理与正常应力一致（R-7）；不一致则停止外推。

### 3. 报告纪律

- 每个数值标注：样本量 n、失效数 r、截尾方式、F(t) 使用区间、图估还是数值法。
- E 值与失效模式成对出现；引用书内激活能表须注明"1980 年代参考值，仅作方向判据"。
- 外推结论必须写加速系数 τ 的完整推导条件（T₀、T₁、F₀、所用模型）。

## B · 边界

1. **OCR 公式完整度**：三函数关系式（1-11~1-17）、加速方程（3-29/3-32/3-34/3-36~3-40）、F(tᵢ)=(i−0.5)/(n+1) 均已从 OCR 原文核对；威布尔分布函数含指数项的完整式（3-1）在 OCR 中丢失上标，本技能不引用其原文形式，需要时查 GB/T 2689 或教科书。
2. **书内数值按 1980 年代工艺**：表 3.1 中位秩表、表 3.2 激活能表只作方向性判据；正式鉴定以 GB/T 2689、GB/T 1772（失效率等级）、JESD22 / AQG 324 现行版为准。
3. **截尾数据的数值分析法**（极大似然、最优线性无偏估计）本书未覆盖，本技能只给图估法；需要精确区间估计时须另查数理统计文献。
4. **失效率等级鉴定的具体抽样表**（§4.3 之后）未在本轮 OCR 抽取范围内，本技能只覆盖抽样方案分类与 α/β 概念，**不给具体抽样数量表**。
5. 与现有技能分工：试验本身的应力设计见 `./chip-fa-stress-test`；把统计结论变成防护动作见 `./chip-fa-prevention`；HV-H3TRB 的失效模式判读见 `./chip-fa-mechanism`。
