# 芯片失效推理方法论（chip-fa-reasoning）

## R · 原文锚点（≤150 字/段）

**R-1 动态原则**（《失效分析——基础与应用（第2版）》§3.1.1）：
> 「所谓动态原则，是指机械产品对周围的环境、条件或位置，总在那里做相对运动。……在失效分析时，应将这些变化条件考虑进去。」

**R-2 一分为二原则**（同书 §3.1.1）：
> 「这个认识论的原则用于失效分析时，常指对进口产品、名牌产品等不要盲目地以为没有缺点。」

**R-3 抓关键问题**（同书 §3.1.1）：
> 「在众多的影响因素和失效模式中，要抓住导致零件失效的关键因素。……关键问题解决了，原来不是关键的问题变成了关键问题，这就要遵循动态原则。」

**R-4 失效系统工程七法**（同书 §3.1.3）：
> 「1）故障树分析法（简称FTA法）。2）特征-因素图分析法。3）事件时序树分析法（简称ETA法）。4）故障率预测法。5）失效模式及后果分析法（简称FMEA法）。6）模糊数学分析法。7）层次分析法（AHP）。」

**R-5 腐蚀产物先分析再去除**（同书 §3.3.1）：
> 「这层腐蚀产物对分析致断原因往往是非常重要的，因而不能轻易地将其去掉。……应先对产物的形貌、成分及相结构进行仔细的分析后再予以去除。」

**R-6 裂纹源区定位的地位**（同书 §3.3.3）：
> 「寻找裂纹源区不仅是断裂宏观分析中最核心的任务，而且是光学显微分析和电子显微分析的基础。」

## I · 骨架（内化的判断逻辑）

1. **推理先于技术**——设备/仪器只产生证据，把证据串成因果链靠推理原则。六原则中最易被违反的是：动态原则（忽略服役期条件变化，如存放期元素偏聚、Cl⁻ 迁移富集）、一分为二原则（对名牌/进口器件预设"不可能有缺陷"）、纵横交汇原则（只在器件本身找，不沿时间轴与使用阶段展开）。
2. **抓关键 ≠ 一次性定案**——关键因素解决后，次级因素会升级为新关键（动态原则的推论），所以纠正措施要排优先级并持续复核，而不是"解决头号因素就归档"。
3. **方法选择由问题结构决定**：
   - 问"哪些原因组合导致顶事件" → FTA（事后归因 + 事前预测两用）；
   - 问"故障如何随时间演化" → ETA（事件时序树）；
   - 问"这批不良归类到哪几类因素" → 特征-因素图（鱼骨图）；
   - 问"量化哪种因素主导" → 多重秩检验/H 检验（见 `./chip-fa-closed-loop`）；
   - 底事件概率不确定、语言模糊（"大约""偏高"） → 模糊故障树（隶属函数处理不确定性），**硬把模糊事件塞进布尔树是常见方法误用**。
4. **断口是失效过程的"黑匣子"，读它的顺序固定**：先保护（防止机械碰撞、氧化污染），再宏观（定性质、定源区、定方向），后微观（定机制、定产物）。任何一步颠倒都会毁掉后续证据。
5. **裂纹源定位是断口分析的"锚"**——源区错了，微观机制与产物分析全都会指向错误的应力历史。宏观五法（特征形貌/拼合宽度/色彩/边缘情况/分叉关系）互相校验，不能只靠单一方法。

## A1 · 案例

**案例 1（进口离心机叶片断裂，R-2 源书）**：某进口离心机叶片断裂，初期多家单位归因"使用问题"，理由是"这样的设备对制造方而言不会出现加工缺陷"；深入分析后确定为**焊接缺陷**引起。教训：对名牌/进口件预设无缺陷，会系统性误导归因方向——**一分为二原则要求对"来源可靠性"本身保持怀疑**。

**案例 2（主裂纹判定：T 型交叉与河流花样，§3.3.3）**：两条裂纹构成"T"字形时，先形成的裂纹阻止后形成者穿越 → **主裂纹是 T 的"横杆"**；多分叉快速扩展时按河流花样判：**主裂纹较宽、较深、较长（主流），裂纹源位于支裂纹扩展方向的反方向**。这两条是封装结构（DBC 基板、焊料层、管腿）多裂纹现场的通用判定逻辑。

## A2 · 触发场景

- 「这个失效分析结论被客户质疑了，推理链哪里站不住」
- 「现场有好几条裂纹，先分析哪条」
- 「断口上的腐蚀产物要不要清掉再拍 SEM」
- 「鱼骨图、FTA、FMEA 到底选哪个做这次归因」
- 「底事件概率估不准，故障树没法算」
- 「失效分析组各做各的，结论互相矛盾，怎么组织」

## E · 执行步骤

### 1. 推理原则自查（分析启动前过一遍）

| 原则 | 自查问题 | 常见违反后果 |
|---|---|---|
| 整体观念 | 系统（设备—环境—人）边界画到第几层？ | 停留在器件级，漏掉环境介质与管理因素 |
| 从现象到本质 | "为什么会出现这个现象"追问了几层？ | 见到疲劳断口即结案，疲劳原因（不下 40 种常见原因）未收敛 |
| 动态原则 | 服役/存放期间的条件变化（温度、湿度、介质、材料内部偏聚、人员）列入了吗？ | 用失效时刻的静态条件解释累积损伤过程 |
| 一分为二 | 对名牌/进口/成熟器件是否预设了"无缺陷"？ | 把设计/制造缺陷误判为使用问题 |
| 纵横交汇 | 沿时间轴（服役阶段）与空间轴（环境）都展开了吗？ | 忽略浴盆曲线不同阶段失效主导因素不同 |
| 抓关键 | 排除了次要因素吗？关键解决后重新排过优先级吗？ | 平均用力，或解决头号因素后不再复核次级风险 |

### 2. 失效系统工程七法选型

| 方法 | 回答的问题 | 何时选它 |
|---|---|---|
| **FTA** | 顶事件由哪些底事件逻辑组合导致？可算顶事件概率 | 有明确顶事件、需要穷尽原因组合；事后归因与事前预测两用 |
| **特征-因素图** | 失效可归类到哪些因素类别？ | 团队梳理阶段，快速撒网 |
| **ETA** | 初始事件沿时间如何演化为各种后果？ | 有安全装置/多重屏障的场景 |
| **故障率预测法** | 系统失效率的定量预估 | 设计阶段可靠性预计 |
| **FMEA** | 各失效模式的后果与风险排序 | 设计/工艺审查（见 `./chip-fa-prevention`） |
| **模糊数学法** | 事件"正常/失效"边界不清、概率语言模糊时 | 底事件概率无法确切给出，用隶属函数表达 |
| **AHP** | 多准则权重排序 | 因素多且需结构化权重决策 |

### 3. 断口处理纪律（动手前必读）

1. **新断口**（来源与损伤过程未知）：防机械碰撞、防手触、防氧化污染；搬运时两半断口对合处垫软物分离放置。
2. **沾污断口**：先水洗再吹干；不彻底再用蒸汽法或超声波法。
3. **潮湿大气锈蚀**：稀盐酸水溶液去锈 → 清水冲洗 → 无水乙醇冲洗吹干。
4. **腐蚀环境断裂**：**产物必须先做形貌、成分、相结构分析，然后才允许去除**。去除方法按优先级：化学法（附材料-溶液-时间对照表）→ 电化学阴极还原法 → 干剥法（AC 纸复型，不影响断口形貌，最优越；取下的复型留样备检）。
5. **过清洗警告**：化学/电化学法兼具显示金相组织的功能，一旦把层片状、带状组织显出来会严重干扰断口判读——**边清洗边观察**。
6. **拍照**：宏观特征（疲劳弧线等）用 30°–45° 斜入射光才显层次；垂直光会掩盖细节。
7. **取样解剖**：确定主断面与源区**之后**才允许解剖，且先记录、拍照。

### 4. 断口分析六项任务（每次断口分析的交付清单）

1. 断裂宏观性质：塑性 / 脆性 / 疲劳？
2. 宏观形貌：纤维状 / 结晶状？有无放射线花样、剪切唇？
3. 裂纹源区位置与数量：表面 / 次表面 / 内部？单源 / 多源？多源时成核先后顺序？
4. 形成过程：裂纹从何处产生、向何处扩展、扩展速度如何？
5. 微观机制：解理 / 准解理 / 微孔？沿晶 / 穿晶？
6. 表面产物性质：有无腐蚀产物？何种产物？**是否参与了断裂过程**？

### 5. 裂纹源区宏观定位五法

| 方法 | 判据 | 适用 |
|---|---|---|
| **特征形貌法** | 纤维区+放射区+剪切唇 → 源在纤维区（静载过载）；人字纹指向末端即源（板件静载）；放射线放射中心即源（圆试件/应力腐蚀/氢脆）；贝纹线同心圆圆心即源（疲劳） | 最直接可靠，首选 |
| **拼合法** | 断口拼合后张口最大处 = 源区 | 管件、板件开裂 |
| **色彩法** | 氧化色/锈蚀最深、最早生成的部位 = 源区 | 有氧化腐蚀环境的断裂 |
| **边缘情况法** | 剪切唇、毛刺、塑性变形随裂纹扩展增大 → 反推扩展方向与源区 | 无特殊花样时**唯一可靠**的方法（如高温氧化蒸汽管断口） |
| **分叉关系法** | T 型交叉：横杆为主裂纹；河流花样：主流为主裂纹，源在支裂纹扩展反方向 | 多裂纹现场 |

**微观机制反推应力状态**（源区部位→应力与缺陷线索）：源于表面一处/两处 → 表面拉应力最大 + 表面加工/材料缺陷（旋转弯曲轴最常见）；源于次表面 → 该处必存在较大缺陷；源于整个表面向内 → 存在严重应力集中的截面突变（如直角过渡）。

### 6. 多学科协同（并行工程 CE 的实施要素）

1. 提出明确具体的失效分析总体要求和目标；
2. 交互作用的、相互协调的**并行**分析过程（各专业同步推进，而非串行传递）；
3. 多学科（专业）人员参与的综合分析机构；
4. 后续阶段与前一阶段之间保持**双向信息流**，随时解决矛盾与不协调。

## B · 边界

1. **源书为机械构件失效分析教材**：断口五法与人字纹/贝纹/河流花样判据针对金属断口。迁移到半导体封装（DBC 陶瓷脆断、焊料层、EMC 塑封料）时，**陶瓷与高分子的断口特征花样与金属不同**，须按其材料手册重新标定，不可直接套用"贝纹线=疲劳"这类金属判据。
2. **本技能不给 FTA 建树的完整操作规范**（建树五规则、最小割集求法在 `./chip-fa-prevention` §FTA，源于电子器件体系）；本技能只给方法选型。
3. **模糊故障树的隶属函数形式**（三角/梯形/LR 型/正态）本书只给概念，具体函数选择须查专门文献。
4. **化学清洗配方**（NaOH+锌粉、稀盐酸、阴极还原电解液等）源自金属断口处理实践，**不得**直接用于半导体芯片、键合线与镀层表面的产物清除——那属于 `./chip-fa-sample-prep` 的领域，须用电子器件专用工艺。
5. 六原则源书成书于机械行业背景，"人/管理"两维的展开见 `./chip-fa-closed-loop`（四M 分析法），本技能不重复。
