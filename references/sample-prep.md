# 芯片解剖制样

## R · 原文锚点

> 塑封器件的封装材料主要是环氧模塑料。以环氧树脂为基体树脂，以酚醛树脂为固化剂，再加上一些填料（如填充剂、阻燃剂、着色剂、偶联剂等微量组分），在热和固化剂的作用下环氧树脂的环氧基开环与酚醛树脂发生化学反应，产生交联固化作用，使之成为热固性塑料。
>
> 化学干法腐蚀也称为等离子刻蚀，是利用高电压产生强电场，引起反应室内的气体电离产生等离子体，利用等离子体将环氧树脂裂变成粉末……**等离子刻蚀的速度和位置可精确控制，能够逐层剥离封装材料，一般用于高集成度的器件开封或进行失效分析。但是由于干法开封过程非常缓慢**……
>
> ——第 9 章 9.2

> 由于失效样品的数量极少，内含重要信息，进行样品制备有很大风险，稍有不慎，会引入新的缺陷，造成失效分析结果的失真，或完全损毁样品，造成失效信息的丢失。
>
> ——2006 §3.3.1

> 然而去除层间介质的同时，必须保留金属化层，这是信号寻迹法失效定位的需要。……去除层间介质，还要保留金属化层正下方的介质，只有这样才能使金属化层有所依托。
>
> ——2006 §3.3.1

---

## I · 骨架：制样的唯一原则是「不破坏你要保留的信息」

开封只是手段，目的是**把失效信息暴露出来**。因此选型的顺序不是"哪种开封方式高级"，而是：

```
你要保留的是什么？
├─ 内部全部结构关系（键合线、芯片、界面） → 机械开封 / 激光开封（定位准、可控）
├─ 芯片表面形貌与金属化层（要逐层看） → 化学湿法 + 等离子干法，逐层剥离
├─ 芯片表面钝化层下（要看下层金属/结） → 去钝化层
├─ 层间介质下的金属（要看某一层金属） → 去金属化层 / 层间介质去除
├─ 截面方向的结构（焊点界面、键合界面、镀层） → 金相切片（机械研磨抛光）
├─ 特定微区的截面（纳米尺度、定点） → FIB
└─ 要做背面分析 / 要看深层 → 芯片减薄 + 背面加固
```

**材料学前提（书里给了具体配方逻辑）**：塑封料是**环氧树脂（基体）+ 酚醛树脂（固化剂）+ 填料/阻燃剂/着色剂/偶联剂**交联固化而成的热固性塑料。正因为是热固性、且含大量填料，所以：
- 不能靠"再软化"来去除 → 必须靠化学溶解或等离子裂解或机械去除；
- 填料（尤其二氧化硅）会让湿法腐蚀不均匀 → 需要干法兜底。

## A1 · 案例：机械开封留下的"可判读现场"

书内图 9-2 给了一个机械开封（钳式 / 旋转式开封机）后的样品：**封装上开出一个窗口，芯片与两侧全部键合引线完整保留**，可直接观察键合区、芯片表面与内引线走向。

这个案例的判读价值：**机械开封的产物是一个"可继续做后续分析"的完整样品**——键合线没断、芯片没被化学液污染，因此可以接着做 SEM/EDS、可以做键合强度测试。而化学湿法开封往往会连带把铝键合线腐蚀掉，此时"键合是否断裂"这个信息就永久丢失了。

**因此：如果你怀疑的问题在键合区或键合线本身，不要先用湿法化学开封。**

## E · 执行步骤

### 0. 剥层的「保三去二」原则（2006 §3.3.1，v2.0.0）

以失效分析为目的的样品制备 = **打开封装 + 去钝化层 +（多层结构）去层间介质**。但去层的同时必须守住三样东西：

| 保留 | 为什么必须保留 |
|---|---|
| **金属化层** | 信号寻迹法失效定位的需要——金属化层是导电通道，不导电就无法寻迹定位 |
| **金属化层正下方的介质** | 让金属化层有所依托，否则结构塌陷 |
| **硅材料** | 器件的核心，去掉了器件就不存在，谈不上失效定位 |

**为什么去钝化层**：钝化层不导电——机械探针无法与金属化层直接接触；SEM/EBT 中其荷电作用会劣化图像与波形质量。

**两个技术要求（决定选哪种刻蚀）**：
- **选择性**：去钝化层/层间介质而保留金属化层和硅 → 要求材料选择性；
- **方向性**：保留金属化层正下方的介质 → 要求腐蚀方向垂直向下（各向异性）。

> ⚠️ **风险红线**：失效样品数量极少、内含重要信息，制样稍有不慎会引入新缺陷（结果失真）或完全损毁样品（信息永久丢失）。**每个样品剥层前先确认：这一步要保留什么信息？**

### 1. 开封方式选择

| 方式 | 原理 | 优点 | 代价 / 限制 | 适用 |
|---|---|---|---|---|
| **机械开封** | 铣/磨/钳式或旋转式开封机去除封装体 | 键合线与芯片保留完整，可继续做后续分析；不引入化学污染 | 精度受限于机械尺寸；对高密度细间距器件风险大 | 需要保留内部结构关系（键合、互连）时首选 |
| **化学湿法腐蚀** | 酸/溶剂溶解环氧模塑料 | 快、成本低 | **会连带腐蚀铝金属化与键合线**；填料导致腐蚀不均 | 只关心芯片表面形貌、不关心键合时 |
| **化学干法腐蚀（等离子刻蚀）** | 高电压强电场电离气体产生等离子体，将环氧树脂裂变成粉末 | **速度和位置可精确控制，能逐层剥离封装材料**；芯片电性能变化最小 | **过程非常缓慢** | 高集成度器件开封；需要逐层控制的场合 |
| **激光开封** | 激光选择性烧蚀封装材料 | 定位精准，可局部开小窗口 | 有热影响区，需控制参数 | 局部开封、保留周边结构 |

**机械开封作业规程（2006 §3.3.2 增量）**：
- 按封装形式选工具：「礼帽状」金属壳 → 手动晶体管开帽器（钳状式/旋转式）；陶瓷扁平封装 → 扁平封装剪切开封器；金属盖陶瓷封装 → 研磨后用利器揭开，**软焊料焊接的金属盖可加热熔化焊料揭盖**。
- **X-ray 先行**：失效样品稀缺且重要，机械开封前先通过 X 射线透视了解封装结构。
- **试验性开封**：必要时用**同类封装结构的良品**先做试验性开封，取得经验后才对失效样品动手。
- **临磨穿即停**：水磨/干磨都要不断在显微镜下观察，**快要磨穿时立即停止再用利器揭盖**，防止碎屑进入封装内。

**化学开封作业规程（2006 §3.3.2 增量）**——塑料封装必须化学开封：
- **安全第一**：必须在**通风柜**中操作，戴防护手套与防护眼镜，严格执行化学实验室安全规程。
- **发烟硫酸（脱水硫酸）法**：对塑料腐蚀强、对铝金属化层腐蚀缓慢。流程：**先 X 射线透视确定芯片位置 → 在芯片对应位置的塑料表面开一个与芯片面积相当的小坑（深度以不触及芯片和引线为限）→ 多次把约 280℃ 的脱水硫酸滴入坑中（或浸入）→ 判定芯片裸露后立即放入冷硫酸 → 浸泡 3~4 s → 无水乙醇或丙酮漂洗 → 去离子水清洗 → 干燥**。
- **发烟硝酸法**：方法同上，硝酸只需加热到发烟即可。

### 2. 芯片剥层（去除钝化层 / 层间介质 / 金属化层）

逐层去除的目的：**暴露失效或缺陷点**。书里给出的手段是化学腐蚀、等离子刻蚀、反应离子刻蚀三类。

作业要点：
- 逐层推进，**每去一层先看一层**（记录形貌），否则一次去过头就无法回溯是哪层出的问题。
- 去除的**选择性**是核心：要除掉 SiO₂/SiN 而不伤铝/铜，靠的是刻蚀选择比，不是"泡久一点"。
- 去金属化层用于**看下层金属或下层结构**；顺序错了会把待观察对象一起去掉。

**三类去层技术的对比（2006 §3.3.3–3.3.4，v2.0.0）**：

| 技术 | 选择性 | 方向性 | 关键风险 / 参数 |
|---|---|---|---|
| **化学腐蚀** | **无**（去钝化层的同时会腐蚀内引线与金属化层未钝化部分，如键合点） | 无 | 条件简单；去 SiO₂ 用 HF:H₂O=1:1，去 SiN 用 85% H₃PO₄ @160℃，去 BPSG 用 10ml H₂O+100ml 36% HCl+10ml 40% HF |
| **等离子刻蚀（PE）** | **有**（CF₄+O₂ 可去 SiO₂/SiN/聚酰亚胺而不伤铝） | **无（各向同性）** | ⚠️ **各向同性腐蚀会掏空金属化层下方的介质 → 金属化层升离、脱离介质层 → 引入新的失效模式**；工作压强 10~50 kPa，射频 450 kHz |
| **反应离子刻蚀（RIE）** | **有**（PE 与溅射腐蚀的折中合成） | **有（各向异性）** | **同时具备选择性与方向性，制样风险最低**；工作压强约 1 kPa（远小于 PE，用涡轮分子泵），射频 13.56 MHz（高于 PE，产生电极间大电场） |

**等离子腐蚀的过程监控（2006 §3.3.3）**：为避免腐蚀不足和腐蚀过度，**每隔一定时间停止反应、取出样品用光学显微镜观察，根据颜色变化确定腐蚀程度**。反应气体压强越大、流量越大，腐蚀速率越快。

**溅射腐蚀（对照项）**：各向异性但**选择性差**（对不同材料的腐蚀速度由材料硬度决定，选择性靠掩膜实现）；压强越小、平均自由程越大，腐蚀速度越大。

> **选型结论**：RIE 是三类中唯一同时满足「保三去二」双要求（选择性+方向性）的技术——多层结构芯片优先 RIE；等离子刻蚀适用于平坦结构，但要预期其升离副作用；化学腐蚀只用于不关心金属化/键合完整性的场合。

**去金属化层的场景（2006 §3.3.5）**：观察 CMOS 氧化层针孔、Al-Si 互溶 PN 结穿钉、确定存储器字线/位线对地短路或开路时常需去金属化层。湿法去铝：30% HCl 或 30% H₂SO₄（室温~50℃），浓度只影响速率、对氧化层和硅无损伤。

### 3. 剖面制样

**（a）金相切片（机械剖面）**
步骤（书内明确）：**截取样品 → 选取观察面 → 机械研磨 → 抛光 → 染色或"缀饰" → 获得平整样品面 → 对关注点观察分析**。

- 用途代表：**焊点界面结构**的剖切形貌。
- 关键提醒：**样品一旦切片就不可能恢复原貌**（书内原话），因此切片必须放在非破坏与半破坏分析之后。
- 染色/"缀饰"的作用是让特定层或缺陷显影，便于判读。

**观察面选取与斜角剖切（2006 §3.3.6，v2.0.0）**：
- 剖切前先按观察目的截取适当观察面，**使所要观察的缺陷与观察面相交**——观察面选取不当，有时根本观察不到目标缺陷。
- **斜角剖切（磨角器）**：观察芯片内部缺陷或测结深时目标区域很狭窄，直角剖切不足以分辨界面区域 → 采用**具有放大作用的斜角剖截面**，需借助固定器（俗称**磨角器**）完成。
- 观察面截取后必须**研磨、抛光、染色或"缀饰"**才能获得较强衬度，使芯片内缺陷显示出来。

**（b）FIB 聚焦离子束剖面**
- 原理：**与 SEM 类似，但用离子源（镓或铟）代替电子源，用离子光学系统代替电子光学系统**。
- 能力：离子束流小时作扫描离子显微镜；**离子束流大时可局部去除和淀积靶材料，作芯片电路修改和局部剖切**。
- 定位：在**微米、纳米尺度**上实现微区剖面、金属切割及金属搭桥等"显微外科手术"，是**芯片级失效定位的重要支撑技术**。
- 与 TEM 的关系：**做 TEM 分析必须用 FIB 做微区定点制样和提取**。

### 4. 光探测类分析的前置要求

若后续要做微光探测 / OBIRCH / TIVA / SEI（见 `./chip-fa-localization`），制样必须保证：
- **从样品顶部或背面均可探测**（背面可及性对多层金属与倒装封装至关重要）；
- 背面分析需要**芯片减薄 + 背面加固处理**（书内第 2 章 2.5.2 列为新材料/新封装带来的新技术挑战）。

### 5. 局部电路修改验证

用 FIB 做**金属切割与金属搭桥**，在样品上人为改变电路连接，验证"若该节点断开/短接，失效现象是否变化"——这是把定位结论变成因果证据的手段，不是修电路。

## B · 边界

1. **制样不可逆。** 每次制样前必须完成非破坏（X-ray / SAM / 热点 / 密封性 / 内部气氛）与半破坏（开封后目检、内部气氛、多余物提取）的信息采集。这一步在所有流程里都排在制样之前，见 `./chip-fa-procedure`。
2. 本章的试剂配方、刻蚀参数、减薄厚度**书中未给出可直接执行的数值**，属产线与实验室专有工艺；本技能只给选型与顺序逻辑，**具体参数必须以本单位工艺文件与现行设备手册为准**。
3. **本章成书于 2015 年**，先进封装（2.5D/3D、TSV、超薄芯片）与宽禁带器件的制样要求更苛刻，需补现行资料。
4. 铜互连 + 低 k 介质的剥层难度与铝互连差异很大（书内第 2 章把"新材料的剥离技术"列为十大挑战之一），不可照搬铝工艺。
5. 本技能不承担**样品毁损责任**：制样前应先确认样品是否为唯一失效件、是否需留存原始状态证据。
