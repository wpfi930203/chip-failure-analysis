# 模块 14 · 加速模型与活化能（v3.1.0，源自 IMA 知识库蒸馏）

> **源等级声明**：蒸馏自 IMA 知识库文章《再谈活化能/激活能 Ea：可靠性的寿命密码》（含可靠性教材 Table 13.2 常用 Ea 值表）
> 与《可靠性试验中几个寿命加速模型》（AEC-Q102 应用向）。L2 证据级；Ea 数值为工程常用值，正式寿命外推应实测或按标准取值。

## R · 原文锚点

> AF = exp[ Ea/R × (1/T_use − 1/T_test) ] —— 高温下劣化反应速率因活化能而成指数级上升，精确测定 Ea 对可靠性寿命预测极为关键。
> ——《再谈活化能/激活能 Ea》

> 铜线能承受的电流密度大约是铝线的五倍（耐电迁移）。
> ——《一文彻底搞透芯片5大失效机理》

## I · 骨架：六大加速模型 → 按主导应力选型

| 模型 | 公式核心 | 主导应力 | 适用失效机理 | 对应试验 |
|---|---|---|---|---|
| **Arrhenius** | L ∝ exp(Ea/kT) | 温度 | 化学反应/扩散类（IMC、腐蚀、TDDB） | HTOL、HTSL |
| **逆幂律** | L ∝ S⁻ⁿ | 电压/功率密度 | 电场驱动类 | HTRB（电压加倍 → 时间缩至 1/2ⁿ） |
| **Eyring** | 多应力乘积 exp(Ea/kT)·S^C | 温度+湿度/电压复合 | 复合应力 | WHTOL |
| **Coffin-Manson** | Nf ∝ ΔT⁻ⁿ，n≈2~5（材料相关） | 温度循环幅度 ΔT | 热疲劳（焊点、键合、焊料层） | TC、PTC |
| **Peck** | 叠加湿度项 (RH)^-m | 温度+湿度 | 湿度腐蚀/迁移 | H3TRB、THB/HAST |
| **Black（EM 专用）** | MTTF = A·J⁻ⁿ·exp(Ea/kT)，n=1~2 | 电流密度 J | 电迁移 | EM/SVA |

## 表 A · 常用活化能 Ea 速查（单位 eV，来自可靠性教材 Table 13.2）

| 失效机理 | Ea (eV) |
|---|---|
| 栅氧缺陷（Gate oxide defect） | 0.3~0.5 |
| 硅体缺陷 | 0.3~0.5 |
| 硅结缺陷 | 0.6~0.8 |
| 金属化缺陷 | 0.5 |
| **Au-Al 金属间化合物生长** | **1.05** |
| 电迁移 EM | 0.6~0.9 |
| 金属腐蚀 | 0.45~0.7 |
| 装配缺陷 | 0.5~0.7 |
| **键合相关（Bond related）** | **1.0** |
| 晶圆制造（化学沾污） | 0.8~1.1 |
| 晶圆制造（硅/晶体缺陷） | 0.5~0.6 |
| 介质击穿（厚度 >0.04μm） | 0.3 |
| 介质击穿（厚度 ≤0.04μm） | 0.7 |
| HCI 表观活化能（JEP122，可正可负） | -0.2~+0.4 |

**工程意义**：Ea 是"把失效机理映射到加速因子"的桥——同一批 HTOL 数据，假设 Ea=0.3 还是 1.0，外推寿命差数量级。**先定机理，再定 Ea，最后算 AF**；顺序颠倒就是数据造假。

## 试验方法分类（设计试验矩阵时用）

- **定时截尾**：规定时间 T₀ 停，失效数 r 是随机的；r 达到拒收线即判不合格。
- **序贯试验**：边试边判，可比常规方法**节约样本 30~50%**（对分法/0.618 法等）。
- **可靠性增长（TAAF）**：试验-分析-改进循环；**只适用于"认真设计仍不达标"的产品，不是掩盖低劣设计的工具**。
- **HALT**：温度 -100~+200℃、温变 70~100℃/min + 六轴随机振动 0~75Grms；**定性**激发设计缺陷（操作极限），不做寿命定量。
- **ALT 加速寿命定量**：恒定应力 + 加速系数 AF，失效比例达 50% 停试 → 累积失效率 F(t) → **威布尔概率纸描点** → 定分布与寿命特征值（中位寿命/特征寿命/可靠寿命）。

## E · 执行步骤

1. 确认主导应力（温度/电压/湿温/循环/电流）→ 表选模型
2. 确认失效机理 → 查表 A 定 Ea（或用两组温度实测数据由 ln k–1/T 斜率反求 Ea）
3. 代入 AF 公式算加速因子 → 由试验时长外推使用温度寿命
4. 数据落威布尔概率纸/拟合（见模块 12），报告必须写明所用 Ea 值及其来源

## B · 边界

1. Ea 值为**经验值**，随工艺/材料体系漂移；正式认证外推须实测 Ea 或引用客户认可值。
2. HCI 的表观活化能可**为负**（温度升高退化反而加快），Arrhenius 模型在 HCI 上方向会反——用模型前先确认机理单调性。
3. Black 方程在先进工艺（≤7nm、3D IC）下外推误差大，行业已视为风险点（见模块 15 EM 节）。
4. 本模块为 L2 二手源蒸馏；公式形式以 JEP122/JESD122 原文为准。
