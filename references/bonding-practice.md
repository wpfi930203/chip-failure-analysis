# 模块 15 · 键合专题：IMC、拉力判据与案例（v3.1.0，源自 IMA 知识库蒸馏）

> **源等级声明**：蒸馏自 IMA 知识库文章《Wire bonding IMC 介绍及可靠性过程中 IMC 的失效机理》
> 《Wire Bond Pull 失效标准——不同线径 Stitch Pull 要求》（JESD22-B120/JESD47L 解读）
> 《金线中微量元素 Pd，Pt，Ca 等配比不同导致焊接不牢——案例分析》《一文了解芯片可靠性测试》附录（AEC-Q006 解读）。
> 本模块与模块 7（机理 P4）衔接：模块 7 给 Au-Al 退化骨架，本模块给**定量判据与实战案例**。

## R · 原文锚点

> IMC 的生成代表焊球与焊盘之间形成了有效焊接，但当其生长达到一定厚度时，由于其自身的脆性又会导致使用过程中的热电疲劳在其内部产生裂痕，这种失效风险由 IMC 生长速度决定，因此 Au-Al > Ag-Al > Cu-Al。
> ——《Wire bonding IMC 介绍》

> JESD47L 中 20μm 金、铜线最小拉力为 2.3g；管控判据应为拉力大于表中相应数值，且失效代码为 5# 或 6#。
> ——《Wire Bond Pull 失效标准》

## I · 骨架一：IMC 退化体系（补强模块 7 P4）

### 三种线材体系的 IMC 风险对比

| 维度 | Au-Al | Ag-Al | Cu-Al |
|---|---|---|---|
| IMC 生长速率 | **最快**（Ea≈1.05eV） | 居中 | **最慢** |
| 可靠性失效主因 | HTSL：**柯肯德尔空洞聚集** → 界面强度急剧下降 | 同左较轻 | HTSL：**裂纹扩展贯穿键合区**（IMC 密度差异致应力集中，从球边缘起裂） |
| 湿热敏感性 | Cl 腐蚀 Au₄Al | — | **HAST 主战场**：卤素离子选择性腐蚀 Cu₉Al₄（富 Cu 相先腐蚀，富 Al 的 CuAl₂ 相"免疫"）→ 微电偶/缝隙腐蚀 → 界面脆断 |
| 特有风险 | 紫斑/白斑脆化 | — | **球吃铝深 → 残铝薄 → IMC 向 Al 焊盘生长"吃穿"残铝 → ball lift**；薄铝产品必须切片验**残铝厚度** |
| 防抑手段 | 金线掺杂（Pd 等）抑制扩散 | — | AEC-Q006：TC/HAST/PTC/HTSL 全部 2X 应力 + CSAM/拉剪/切片 |

**关键定量对比（AEC-Q006 解读）**：Au-Al IMC 厚度是 Cu-Al 的 **3~5 倍**，生长速率高 **10 倍以上**；金线高温失效 = 柯肯德尔空洞，铜线 = 裂纹扩展——**同样开路失效，两种线的形貌判读逻辑不同**。

### HAST 中 IMC 失效的双通道（判读用）

1. **水汽侵入 IMC 层 + 偏压 → 电化学腐蚀脱球**（主通道）
2. **卤素离子（Cl⁻，来自模塑料缓蚀剂/阻燃剂）→ 选择性腐蚀富 Cu 相 IMC**；正偏置引脚吸引卤素离子 → 腐蚀呈**方向性**（偏压侧不对称），无偏压时轴对称——**腐蚀分布的对称性可反推偏置状态**

## I · 骨架二：Wire Pull 定量判据（JESD22-B120 + JESD47L）

### 9 种失效代码（JESD22-B120）

| 代码 | 断裂位置 | 判定含义 |
|---|---|---|
| 1~3# | 球/颈部异常（一焊点失效） | **拒收模型** |
| 4# | 线颈拉断 | 常见，可接受 |
| **5#** | 线体中间拉断 | **理想模型** |
| **6#/7#** | 二焊点（鱼尾）拔起，分界看**鱼尾残留百分比** | 封装厂管控的"鱼尾残留 >X%"本质就是要求至少为 6# 断裂 |
| 8~9# | 特殊异常 | 个案分析 |

### 判据的正确打开方式（两条缺一不可）

1. **拉力值 ≥ JESD47L 按线径的最小值**（例：20μm 金/铜线 ≥ **2.3g**——经验口诀"stitch pull>2g"偏松，会放过批界问题）
2. **失效代码为 5# 或 6#**——只看拉力值不看断点位置，会把"高拉力但从焊球界面拉脱"的假合格放进量产

## A · 案例：BHAST 96h 后 15% open（金线微量元素）

**现象链**：T0 在线测试全 PASS，X-ray 连线正常，SAT 无分层，首次切片无异常，手动 IV 确认 open——**"找不到问题就是最大的问题"**。

**破局路径（可直接复用）**：
1. **TDR 定位**：测发射/反射脉冲时间差 Δt 判 open 在芯片侧/基板侧/线上（精度：区分侧，不能到 pad/球/neck）
2. **逐球切片**：切到第 N 颗发现异常——铝层下方 **TaN 保护层与铜柱分层（peeling）**
3. **机理链**：BHAST 高温高湿 → 金铝 IMC 快速生长 + 柯肯德尔空洞 → 应力不均；**残铝已被 IMC 全部消耗** → 应力直接作用于 TaN → peeling → 接触不良 open
4. **根因**：**金线微量元素配比**（Pd/Pt/Ca/Mg 比例影响 IMC 生长速率与方向）；DOE 证明键合球形貌完美（残铝 60%）仍失效 → 排除键合参数，锁定线材
5. **纠正**：换线——**提高 Pd 含量 + 增加 Ca（二者抑制 IMC 生长）、去除 Pt** → BHAST 96h 对比切片确认改善

**方法论要点**：T0 全 PASS + 可靠性激发（BHAST）才暴露的失效，优先怀疑**材料体系（线材/IMC 动力学）而非键合参数**；切片切一球没异常就继续切，"直到找到 open 的点"。

## I · 骨架三：Ball Shear 定量判据（JESD22-B116B，一手标准蒸馏）

### 适用与设备（B116B §1/§3）

- 覆盖 **15–76 µm（0.6–3.0 mil）** 热超声球键合；球高 **≥4.0 µm**（设备极限）；楔形焊仅定性参考（Annex B：粗线 ≥3 mil、压缩区高 ≥32 µm≈¼线径）。
- 显微镜 **≥70X**（15 µm 细线要更高）；球径测量精度 ±2.54 µm；不对称球取 (d_max+d_min)/2；剪切面积 **A = πd²/4**。
- 剪刀位置参数 h：高于键合面、且**低于球中心线**（碰面→读数虚高无效；够不到中心线 → Annex C 只作定性）。

### 失效代码（§4.6，Type 1–5）与数据有效性

| 代码 | 形貌 | 有效性 |
|---|---|---|
| **Type 1** | Au/Al：分离面在 IMC 层内/多平面/线上留键合面金属层 | **有效**（正常剪切形貌） |
| **Type 2** | Cu/Al、Cu/Cu、Au/Au：界面或体材分离（Cu-Al IMC 极薄通常不可见，故定义不用"IMC"措辞） | 有效 |
| **Type 3** | **Cratering**：键合面下层氧化物/硅崩落 | **键合工艺造成的 crater 有效并计入**；pad 下硅/金属化**既有缺陷**造成的 crater 无效剔除，但**必须追查** |
| Type 4 | 剪刀刮/犁到芯片表面 | **无效剔除** |
| Type 5 | 剪刀跳过键合球 | **无效剔除** |

- **判据不在 B116B 里**：pass/fail 数值已全部移交 **JESD47**（JEDEC 政策：试验方法只写怎么做）；铝楔形焊例外（Annex B.5：最小剪切值 ≥ 线材厂商抗拉强度，且**键合 footprint 覆盖率 ≥50%**，可算 Cpk）。
- **金属化层被整体拔起**（球带走 pad 金属）→ 提示 pad/引线框/基板镀层附着力弱于键合强度 → 查键合工艺、晶圆后道（BEOL）、镀层工序——与模块 7 第 3 类因素（pad 拔起）直接对应。

### 去封（decap）对剪切值的影响（Annex D——Cu 线专属陷阱）

- Au 线：腐蚀去封可控、可复现，**可做批间对比**；剪切值偏低但系统性可比。
- **Cu 线：腐蚀液会攻击 Cu 球/线**，损伤程度取决于塑封料化学、Cu 线类型（裸 Cu vs Pd-Cu）、腐蚀介质、样品应力历史——**批间对比不可靠**。
- **两步去封**：先激光/机械铣削去大部分塑封料（激光不伤铜线但伤芯片面，须保留芯片面上方一层），再短时化学腐蚀收尾——**最小化化学暴露时间**。
- **过腐蚀自检法**：先做 wire pull，若拉力显著低于未去封典型值 → 球键合大概率也已损伤，**该样品不得再用于剪切测试**。
- Cu 球的"球径↔接触面积"比值随线径增大而下降且不稳定（≥2 mil 明显），故 **Cu 球判定用键合接触面积（%IMC，SEM 图像算法测 Cu-Al IMC 占比）而非球径换算**——这是 Au/Cu 判定体系最关键差异。

## E · 执行步骤（键合脱落/open 问题接本模块）

1. 先按模块 7 五类因素定位"脱落面在哪侧"（P4 冶金类 vs 工艺类）
2. 冶金类 → 本模块三线材表分辨 **Au-Al vs Cu-Al 判读逻辑**（空洞聚集 vs 裂纹扩展 vs 残铝耗尽）
3. 量化判定 → 拉力复测（线径查 JESD47L 表）+ 失效代码（B120）+ 切片验**残铝厚度**
3a. **剪切测试 → B116B 流程**：球径测量 → A=πd²/4 → h 位于中心线下 → 按失效代码剔除 Type 4/5 → **判据查 JESD47**；Cu 球用 %IMC 接触面积口径
4. HAST 类腐蚀 → 看腐蚀分布对称性反推偏置，EDS 找 Cl⁻
5. 纠正措施 → 键合参数 DOE 之外，**线材微量元素配比是常被遗漏的一层**（Pd/Ca 抑制 IMC）
